# 卫华漫剧·剧本脚本（weihua-manju-juben）

## Overview

把「真实素材 → 故事线 → 分幕剧本 → 台词旁白」串成一条线。核心约束：所有事实来自用户给的素材，人物可艺术化，数据与客户名不可编。

## 硬性规则（违反即失败）

1. 事实边界：交付节点、设备型号、项目名只写用户给过的；没有的标「待补：XX」。
2. 一集一个冲突：90 秒只解决一件事，不堆卖点。
3. 前 5 秒必须有钩子：动作、声音或一句反常识台词，不用旁白开头。
4. 台词口语化：一句话不超过 18 字，能念出来不打结。
5. 品牌露出克制：设备铭牌、厂区标识最多 2 处，不硬广。
6. 涉及安全、质量承诺的台词，须与公司对外口径一致，拿不准就标「待品牌部确认」。

## 工作流

1. 读素材，抽出人物、场景、关键转折三张清单。
2. 定故事线：钩子 → 阻力 → 转折 → 落点，写成一页大纲给用户确认。
3. 按幕写剧本：分幕、场面、动作、台词、旁白。
4. 配人物小传与场景说明（供分镜与生图使用）。
5. 输出剧本稿 + 旁白稿，标出需人工确认的事实点。

## 产出与交付

分幕剧本（含台词、旁白、镜头提示）、人物小传、可交付的旁白稿。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不代替品牌部定对外口径、不写涉及未发布产品的剧情、不生成真实客户姓名与合同金额。
