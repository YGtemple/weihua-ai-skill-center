# 场景模块：年度总结表彰大会讲话

## 目录

- 场景定位
- 默认结构
- 分段写法
- 不同经营情境
- 功能型大纲
- 篇幅与详略

## 一、场景定位

年度总结表彰大会同时承担四项任务：致敬先进、评价全年、统一认识、部署新年。总裁讲话应把荣誉激励与经营部署连成一体。

默认主线：

> 荣誉属于奋斗者 → 奋斗形成了什么结果和能力 → 还有哪些差距 → 下一年如何共同再出发

不要把表彰只写成开场的一个词，也不要写成季度经营会或纯颁奖致辞。

## 二、默认结构

采用“开场祝贺致谢 + 五个主体部分 + 结尾动员”的完整骨架。五个主体部分可按素材合并，但功能不宜全部缺失。

1. **开场**：会议定位、祝贺先进、感谢员工及经确认的支持方。
2. **总体回顾**：年度坐标、行业背景、核心经营判断、总体致谢。
3. **年度盘点**：按四至六个能力板块复盘代表性成果。
4. **察势找差**：外部变化与机会、内部关键短板、信心基础。
5. **新年部署**：发布年度主题，部署五至八项重点工作。
6. **荣誉动员**：把先进精神转化为全员行动，收束共同愿景；时间合适时加入新春祝福。

各部分小标题从当年判断中提炼，不机械照抄历史稿标题。

## 三、分段写法

### 1. 标题与署名

默认形式：

```text
[年度主标题]
——在卫华集团[总结年度]年度总结表彰大会上的讲话
集团总裁 [姓名]
[讲话日期，可选]
```

也可按会议正式安排使用“[总结年度]工作总结与[部署年度]工作安排”作副标题。会议年份、总结年度和部署年度以正式会议名称为准。

### 2. 开场：先把荣誉交给奋斗者

建议 2—4 个自然段：点明会议目的；向受表彰集体和个人祝贺；向全体员工致谢；按实际议程感谢家属、伙伴或嘉宾；自然承接主体。

不默认“上午好”，不虚构刚才哪位领导发言、宣读或颁奖。

### 3. 总体回顾：先作经营判断

用一段交代行业环境和企业年度坐标，再用核心指标作总体评价。订单、收入、净利润、回款和现金流分别判断，不能用单项亮点概括全部经营结果。

推荐链路：外部环境 → 全员奋斗 → 核心结果 → 能力变化 → 荣誉归因与感谢。

### 4. 年度盘点：从工作清单上升为能力变化

根据材料选择四至六个板块：

- 市场与产品：优质订单、产品结构、新大特、海外市场、重大项目；
- 技术与创新：产品迭代、工艺改进、数字化、人工智能、技术资质；
- 生产与履约：效率、交付、供应链、库存、服务和“卫华速度”；
- 质量与安全：质量体系、质量顽疾、认证、安全环保、合规底线；
- 经营与管理：利润、成本、回款、现金流、流程、机制改进；
- 人才与文化：干部队伍、人才培养、激励、协同、员工关怀、公益文化。

每个板块采用“概括句 + 两至三项证据 + 经营意义”。事实不足时减少板块，不硬凑六项。

若有正式表彰事迹，选择一至两个与年度主线最贴合的案例，写清任务、行动、结果和精神。没有完整材料时不虚构姓名、人数和情节。

### 5. 察势找差：提气不粉饰

外部部分只保留与集团业务直接相关的变化。内部部分选择三至四个最制约发展的矛盾，写清具体表现和经营影响，避免笼统说“意识不强”。

结尾给出可验证的信心来源，如产品、技术、品牌、团队、客户基础和已验证机制。

### 6. 新年部署：讲清怎么干

先提炼并解释年度主题。主题默认两个语义互补的短分句，应同时回应现实矛盾和年度行动，不自动复用历史主题。

再按正式计划选择五至八项重点：市场订单、产品技术、质量交付、利润成本、回款现金流、客户协同、管理机制、人才文化、安全合规等。每项至少包含“行动对象 + 具体动作 + 责任或机制 + 结果指向/风险边界”中的三项。

量化目标、绩效承诺和奖惩政策只能引用已批准内容。学习先进要落到客户意识、质量意识、协同精神或攻坚方法等具体行动。

### 7. 结尾：从年度任务回到共同奋斗

通常 2—3 段：一句有文气但不过度雕琢的过渡；重申共同信念和行动要求；按时间送上祝福。

诗文、生肖、周年、新春祝福只选合适支点，避免连续引用名句和堆叠感叹号。

## 四、不同经营情境

| 情境 | 写法调整 |
|---|---|
| 核心指标总体较好 | 充分讲成果与先进，但仍保留结构性短板 |
| 订单或收入较好、利润承压 | 突出规模与效益矛盾，把毛利、成本、回款和现金流放在中心 |
| 多项核心指标未达预期 | 减少庆功式措辞，肯定真实进展，直说差距并讲清扭转机制 |
| 表彰事迹丰富 | 增加一至两个案例，以其精神串联成果和部署 |
| 素材不足 | 交付功能大纲或带待核标记的征求意见稿，不用旧稿事实填充 |

## 五、功能型大纲

```text
标题：[年度主题]
副标题：[会议正式名称]
署名：[集团总裁姓名]

开场：会议定位；祝贺与致谢
第一部分：年度坐标；核心指标判断；荣誉归因
第二部分：四至六个能力板块；可选先进案例
第三部分：外部变化与机会；内部短板；信心来源
第四部分：年度主题；五至八项重点；学习先进的行动
第五部分：年度动员；荣誉收束；可选节日祝福
```

## 六、篇幅与详略

完整讲话默认 5000—7000 字，用户指定篇幅或时长时优先服从。

| 模块 | 建议占比 |
|---|---:|
| 开场祝贺与致谢 | 5%—8% |
| 总体回顾与年度盘点 | 28%—35% |
| 形势、机会与内部差距 | 17%—23% |
| 新年主题与部署 | 35%—43% |
| 结尾动员与祝福 | 4%—7% |

短稿保留祝贺、核心指标判断、关键成果、主要矛盾、重点行动和结尾。长稿增加真实案例与机制解释，不增加空泛铺陈。
