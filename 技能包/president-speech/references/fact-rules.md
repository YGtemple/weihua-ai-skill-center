# 事实与经营数据核验规则

## 目录

- 事实边界
- 经营数据口径
- 人物、表彰与承诺
- 强判断和外部事实
- 文字与年份检查
- 交付前核验

## 一、事实边界

### 1. 来源优先级

公司当期正式数据、正式总结、表彰文件和已批准计划优先于历史讲话。历史讲话中的事实只证明“当时这样写”，不证明新一期仍成立。

### 2. 建立事实台账

| 字段 | 要求 |
|---|---|
| 事实/指标 | 使用原材料正式名称 |
| 期间 | 全年、截至某月、季度、单日等 |
| 单位与范围 | 万元/亿元、%/台/项；集团、重机、重装或产品 |
| 目标与实际 | 分开记录，不混在同一句 |
| 来源位置 | 文件名、工作表、单元格或原文段落 |
| 状态 | 最终、暂估、预测、目标、待核 |
| 拟用位置 | 总评、成果、问题或部署 |

### 3. 缺失与冲突

- 缺失事实用 `[待核：具体事项]` 标记，正式净稿前清零。
- 同一指标多来源不一致时，不自行选择更好看的数字；回到责任部门最终版或请用户确认。
- 不用常识补齐公司事实，不将计划写成已完成，不将签约写成收入，不将中标写成交付。
- 历史稿署名、称谓或领导分工不一致时，以当期正式信息为准。

## 二、经营数据口径

### 1. 核心指标分别判断

订单、收入、净利润、回款和现金流分别对照目标与同期，不以其中一项推断另一项。总体评价必须能被所有同层核心指标支撑。

讲话只选能支撑主线的指标，不把整表搬进正文。市场结构、运营效率、质量技术和组织保障指标作为补充证据。

### 2. 期间完整性优先于表名

表名写“1—12月”不代表所有字段都有全年数据。逐格检查实际期间；只填到某月时，只能写“截至某月”或不作全年结论。

### 3. 单位、同比和完成率

- 内部计算保留原值；万元换算亿元时除以 10000，并统一正文精度。
- 比例数值与百分数正确转换，如 `0.061` 对应 `6.1%`。
- 完成率、同比、剩余目标测算和金额换算使用计算工具或可复算脚本。
- 区分“增长10%”“提高10个百分点”“完成率100%”，不得混用。
- 正文可适度圆整，但精确台账与宣读值分开保存。

### 4. 合并项与子项

产品订单、海外订单等子项已包含在集团订单总额中时，只用于说明结构，不再次加到总额。集团、重机、重装和单项产品不得混写范围。

### 5. 数字关系复核

对“剩余时间—剩余目标—月均要求”“当期月均—目标月均”“去年基数—同比增幅”等派生关系做交叉复算。发现不合常理或相互矛盾时标记待核，不自行解释，不沿用旧稿。

## 三、人物、表彰与承诺

1. 姓名、职务、奖项、获评数量、先进集体和个人名单以当期正式文件为准。
2. 先进事迹写清任务、行动、结果和精神；关键情节均有来源，不把团队成果随意归到个人。
3. 未提供完整名单时，可概括向“受表彰的先进集体和个人”致意，不虚构代表性姓名或人数。
4. 家属、嘉宾、合作伙伴出席和致辞情况不得猜测。
5. 股权、奖金、绩效、购车优惠、晋升和福利承诺必须有正式批准依据。
6. 客户、项目、事故、投诉和问责信息注意披露边界，优先使用经批准的匿名化表述。

## 四、强判断和外部事实

### 1. 公司强判断

- “创历史新高/纪录”：有历史同口径比较。
- “首台套/填补空白/行业领先/唯一”：有正式验收、认证或权威材料。
- “大幅增长/跨越式增长”：有明确基期与幅度；否则用“增长”。
- “圆满完成/全面完成”：所有被概括的同层指标均达到目标。
- “零事故/100%”：统计期间、范围和责任部门口径完整。

### 2. 宏观与行业事实

- 使用讲话时点之前可核验的权威来源，记录发布日期、统计期间和原始链接。
- 区分已发生事实、官方目标和总裁判断，不将未来政策、会议或项目结果写成已经发生。
- 宏观内容必须服务集团业务，旧讲话中的政策、行业数据和国际事件重新核验。

## 五、文字与年份检查

1. 会议年份、总结年度和部署年度保持一致逻辑，以正式会议名称为准。
2. “百分点”不得写成“个百分”；中文约数与阿拉伯数字按语境统一。
3. 同级编号连续，不出现缺号、跳号或同级混用多套编号。
4. 清除起草括注、口误、重复标点、现场提示和编辑说明。
5. 历史年度主题、生肖、周年、新春祝福和诗文按新讲话时点重新判断。

## 六、交付前核验

1. 每个数字能否回到源文件具体位置；
2. 每个“全年”是否确有完整全年数据；
3. 目标、实际、同比和完成率是否混用；
4. 集团、重机、重装和产品范围是否混淆；
5. 总体成绩判断是否被利润、现金流等短板证伪；
6. 所有人物、荣誉、项目、议程和激励承诺是否有当期依据；
7. 派生数字关系是否经过复算；
8. 外部事实是否在讲话时点前已公开且可核验；
9. 待核项是否已解决，或在征求意见稿中逐项明示。
