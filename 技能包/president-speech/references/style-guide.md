# 总裁公共风格资产

## 一、角色与稳定风格

### 1. 经营判断与执行抓法并重

总裁不是只复述经营报表，也不只讲愿景，而是解释数据背后的矛盾，并把行动、责任、机制和结果讲清楚。

常见推进链：

> 数据或事实 → 经营判断 → 问题及影响 → 行动与责任 → 结果检验

### 2. 肯定成绩与直面问题并存

成绩讲得具体、提气，问题讲得坦率、准确。既不一味颂扬，也不以批评代替部署。

可变化的表达关系：

- 既要看到突破，更要看到效益和能力的差距；
- 肯定成绩是为了提振信心，直面问题是为了继续前进；
- 订单增长不等于利润增长，项目中标不等于完成交付；
- 越是在压力之下，越要守住质量、现金流和长期能力。

### 3. 战斗感与长期主义相融

紧迫感落在抢订单、保履约、提质量、控成本、抓回款、强团队；长期主义落在技术积累、产品升级、人才梯队、文化根基和共同愿景。避免只有“冲、拼、干”的情绪，没有路径。

### 4. 经营要求与团队温度相融

尊重奋斗者，关注员工成长、激励兑现和荣誉共享。具体激励、奖金、股权或福利承诺必须有正式依据，不为增强感染力自行加码。

## 二、叙事与句式

### 1. 用概括句统率事实

优先采用“概括句 + 事实证据 + 经营意义”。概括词必须从本次材料中提炼，事实不足时减少分组，不硬凑三项或六项。

### 2. 长短句交错

长句解释形势、因果和机制；短句下判断、提要求、收束段落。一段通常只承担一个核心意思，连续排比后用朴素短句落地。

### 3. 按语义选择逻辑句式

- 对举：“既要……，更要……”
- 判断：“不是……，而是……”
- 因果：“这些问题不解决，……就无法……”
- 递进：“不只是……，更是……”
- 要求：“各系统要……，各级干部要……，每一位员工都要……”
- 结果：“最终用……来检验。”

这些句式是可选工具，不是每段必用模板。

### 4. 使用自然讲话层级

完整宣读稿使用“一、”“（一）”“一是”“第一”等自然层级，编号连续且同级形式一致。不要输出 Markdown 标题，不出现“以下是讲话稿”“本文将从”“综上所述”等生成痕迹。

### 5. 清理起草括注

正式净稿不保留“前排领导举例”“可尝试”“这里补充”“临场发挥”等括注。确有价值的口语内容改写为可直接宣读的正文。

## 三、经营语义资产

以下词汇来自既有讲话，只作为可复用语义资产，是否使用以最新正式口径和本次主线为准：

- 经营结果：优质订单、收入、净利润、回款、现金流、产品结构、盈利能力；
- 市场产品：重机、重装、新大特、门机、核电、航天、海工、港口、海外市场、差异化；
- 运营履约：卫华速度、质量顽疾、设计源头、工艺优化、生产交付、供应链、服务闭环；
- 管理机制：管理提升、降本增效、协同作战、结果导向、问题清单、闭环反馈；
- 团队文化：卫华人、奋斗者、干部带头、集团一盘棋、让奋斗者得到褒奖；
- 风险底线：质量红线、安全底线、依法合规、保密、廉洁。

可变化使用“订单是企业生存根基”“现金流是企业的血液”“质量是不可逾越的红线”等判断，但同篇不堆砌过多类似警句。

“没有独家资源、没有天然壁垒，唯有全员同心、艰苦奋斗”体现跨篇稳定的奋斗逻辑，可结合当期事实改写，不机械照抄。年度主题和固定结尾不自动复用。

## 四、现场表达

### 1. 开场服从会议目的

表彰会突出祝贺和荣誉共享，季度会突出经营判断，半年度会突出承上启下，收官会突出目标冲刺，专项活动突出为什么做和怎么做。领导职务、发言议程、家属或嘉宾出席情况不得猜测。

### 2. 人物与案例服务主线

案例写清任务、行动、结果和精神，不写成颁奖词合集或活动流水账。没有完整材料时不虚构姓名、人数、奖项和情节。

### 3. 部署体现总裁抓法

优先写谁牵头、哪个环节先改、形成什么机制、用什么结果检验、什么边界不能突破。“我已安排”“由我牵头督办”等个人安排只能在真实、获授权且符合讲话时点时使用。

### 4. 结尾形成行动与愿景收束

通常回到会议主题、共同信心和下一步行动。诗文、生肖、新春、周年等表达仅在时间匹配且事实准确时使用，避免名句和感叹号堆叠。

## 五、常见偏差

| 偏差 | 修正 |
|---|---|
| 写成部门工作总结 | 用经营判断和能力变化重组事实 |
| 写成纯战略致辞 | 增加经营矛盾、执行机制、责任和结果检验 |
| 只讲成绩不讲问题 | 写清关键差距及其经营影响 |
| 只讲危机不讲机会 | 补充与集团能力相关的可信机会和信心基础 |
| 部署全是“加强、提升、持续” | 补行动对象、机制、责任、边界或结果 |
| 为显气势堆满口号 | 用具体判断和事实支撑，每段突出一个核心意思 |
| 把旧稿换年份复用 | 所有事实回到当期材料重新核验 |
| 为统一格式硬凑固定部分 | 根据场景和素材调整层次 |
| 保留口误、编号断档和编辑括注 | 交付前统一层级、文字和宣读表达 |
