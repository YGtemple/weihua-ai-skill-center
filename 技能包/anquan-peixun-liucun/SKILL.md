# 安全培训与交底留痕（anquan-peixun-liucun）

## Overview

「场次识别 → 人员比对 → 材料汇编 → 缺漏清单」四步流水线。核心约束：只归集已有材料，缺的人就是缺，绝不代签、不生成虚假签到。

## 硬性规则（违反即失败）

1. 不伪造：任何签到、签字、试卷都只能来自用户提供的原件。
2. 按场次分组：不同培训、不同日期分开汇编，不混成一份。
3. 人员名单以签到表为准，试卷与照片只用于核对覆盖情况。
4. 缺签缺卷逐人列出姓名 + 班组 + 缺什么，便于补做。
5. 照片按场次归档，不识别画面内容。
6. 交付时提示：正式迎检前须人事/安全部门复核签字的真实性。

## 工作流

1. 识别培训场次：按培训通知的时间、主题、覆盖班组分组。
2. 读取签到表人员名单，建立应到/实到对照。
3. 比对试卷份数与签到人数，标出未交卷人员。
4. 把交底记录与照片按场次挂进汇编。
5. 输出留痕汇编、缺漏清单、待办提醒。

## 产出与交付

培训留痕汇编（签到 + 试卷 + 照片）、缺漏人员清单、下次培训待办。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不做培训效果评价、不生成培训内容、不代任何人签字。
