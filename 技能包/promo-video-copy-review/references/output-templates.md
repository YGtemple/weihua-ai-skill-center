# 三种交付模板

优先级定义（三套模板通用）：

- **P0 必改**：触碰红线、事实错误、口径不一致、声画不符。不改不能发。
- **P1 建议改**：影响传播效果和品牌形象，改了明显更好。
- **P2 可选**：锦上添花，用户可自行决定。

---

## 模板 A：单篇审核报告

````markdown
# 审稿结论：《稿件标题》

**结论：退回修改（68 分）** — 事件本身没问题，但视频装不下这段文案，且人物名单与字幕不一致。

| 项 | 内容 |
|---|---|
| 提交人 / 日期 | ××× / 11-10 |
| 稿件类型 | 宣传视频（27s 竖屏，字幕+口播） |
| 字数 / 时长 | 212 字 / 成品 27.4 秒 |
| 用途判定 | 对外发布，企业动态性质（非商业广告） |

## 四维得分

| 维度 | 得分 | 主要扣分 |
|---|---|---|
| A 合规与宣传风险 | 30/40 | A1 关系表述(–6)、A5 肖像授权(–4) |
| B 事实与信息准确 | 16/25 | B1 缺年份(–4)、B2 名单不一致(–5) |
| C 品牌调性与口径 | 12/15 | C3 称谓混用(–3) |
| D 结构与传播转化 | 10/20 | D2 字数超载(–4)、D5 无企业落板(–4)、D1 无钩子(–2) |

## P0 必改（3 项）

1. **[B2] 人物名单与视频字幕不一致**
   - 文本："卫华集团总裁杨尊加，卫华重机总经理李苗苗等公司高管受邀参加"
   - 视频字幕："卫华集团董事长胡旭、总裁杨尊加等公司高管受邀参加"
   - 处理：以官方签到名单为准统一两版，并在稿中写全"职务+姓名"，不要用"等公司高管"掩盖。

2. **[D2] 字数超出 27 秒承载量近一倍**
   - 212 字 ≈ 53 秒口播，成品仅 27.4 秒，字幕会三四句挤一屏
   - 处理：按下方"改后建议"压到 105 字以内，或延长至 50 秒。

3. **[A1] 关系表述不足，读者可能误认为企业主办**
   - 现稿只写"在××举行"+"高管受邀参加"，顶栏通栏又长时间挂在企业名上
   - 处理：首句明确"由××主办"，企业侧统一用"受邀出席"。

## P1 建议改（2 项）

4. **[D5] 结尾是活动口号，没有企业落板** — 观众记不住发布方。建议末尾加 2 秒"卫华集团"落板。
5. **[D1] 开头无钩子** — "11月6日，××活动在××举行"是通报句式。建议前置一句价值主张。

## P2 可选

6. 价值观四词"厚德、笃行、担当、共赢"可做成 4 个字卡依次出现，比整句字幕更有记忆点。

## 待补信息（请向对应方核实）

| 事项 | 找谁核 |
|---|---|
| 参会名单与职务（胡旭 / 杨尊加 / 李苗苗） | 人事或活动对接人 |
| 活动主办方全称、年份 | 主办方通知或邀请函 |
| 现场人物特写是否有肖像授权 | 行政/法务 |

## 改后建议（可直接替换）

> 11 月 6 日，由××主办的"河南省民营企业金秋创新学习活动"在郑州黄河迎宾馆迎宾会堂举行。卫华集团董事长胡旭、总裁杨尊加等高管受邀出席，与省内民营企业家共探转型升级路径。
>
> 从行业趋势研判到标杆案例拆解，这场学习把"存量时代怎么突围"讲透了。卫华集团始终坚守"厚德、笃行、担当、共赢"，把每一次学习，变成下一步的动作。
````

## 写报告的语言要求

- 结论放第一行，用"结论：xx（分数）— 一句话原因"
- 每条必改项写：**编号 + 问题 + 稿子原句 + 怎么改**，四件套缺一不可
- 引用原句用引号原样摘，不改写
- 涉及"待核实"的，写清找谁核，不留悬空
- 不写"整体不错，还可以再打磨"这类不能执行的评价
