# 合规红线与常见风险

审的是"能不能安全发出去"，不是"合不合广告法"。先判断稿件性质，再套对应尺度——这一条错，后面全错。

## 先分类：这是广告还是企业动态

| 稿件性质 | 适用尺度 | 说明 |
|---|---|---|
| **商业广告**（推产品、服务、促销、招商、加盟、卖课） | 最严。《广告法》全面适用，绝对化用语、数据出处、功效表述都要卡 | 带货、引流、留联系方式、报价、承诺效果的，一律按广告审 |
| **企业动态/新闻通稿**（参会、获奖、签约、公益、人事） | 中度。主要是事实准确 + 不虚假宣传 + 不暗示政府背书 | 不受广告法绝对化用语条款约束，但受《反不正当竞争法》虚假宣传约束 |
| **内部宣传**（员工群、内刊、年会） | 宽松。只看准确、口径统一、不泄密 | 不得含未公开的经营数据、客户名单 |

判不准就问：**这篇会不会挂价格、留联系方式、引导购买或加盟？会，就按广告审。**

## 红线清单（命中即驳回）

1. **变相使用国家机关、国家机关工作人员的名义或形象**（《广告法》第九条第一款第二项）。企业参加政府/协会活动对外宣传，只能写事实关系（受邀出席、参加、参会），不能出现"政府指定""政府推荐""××部门支持"等背书性表述，也不能把政府会议场景当自家主场用。
2. **人物姓名、职务错误**，尤其政府人员、协会负责人、合作方高管。不能用"相关领导""某负责人"糊过去。
3. **无法举证的最高级表述**用于自身商业优势：第一、唯一、首创、顶级、国家级、最佳、最大、领先、独家。
4. **编造数据、荣誉、资质、合作方**，或引用"据调查""数据显示"而无主体、无出处。
5. **未经授权**使用可识别个人肖像（特写、姓名同框）、他人企业标识、商业音乐、商用字体。
6. **虚假承诺**：保证、包过、永久、一次见效、稳赚、零风险。
7. **特殊行业越界**：医疗/药品/器械/保健食品涉及疗效、治愈率；金融涉及保本保收益；教育涉及升学率、名师保证；房地产涉及升值、学区承诺。

## 关键条款速查

- **《广告法》第四条**：广告不得含有虚假或者引人误解的内容，不得欺骗、误导消费者。
- **第八条**：商品/服务的性能、功能、产地、用途、质量、规格、成分、价格、生产者、有效期限、销售状况、曾获荣誉等，应与实际情况相符。
- **第九条**：广告不得使用"国家级""最高级""最佳"等用语；不得使用或变相使用国家机关、国家机关工作人员的名义或形象。
- **第十一条**：使用数据、统计资料、调查结果、文摘、引用语，应真实、准确，并表明出处。
- **第十六条、第十七条**：医疗、药品、医疗器械广告的限制；非医疗机构不得在广告中涉及疾病治疗功能。
- **《反不正当竞争法》第八条**：不得对商品性能、功能、质量、销售状况、用户评价、曾获荣誉等作虚假或引人误解的商业宣传。
- **《民法典》第一千零一十九条**：不得侵害他人肖像权；未经同意不得制作、使用、公开他人肖像。
- **《互联网广告管理办法》**：短视频、直播等形式发布广告应显著标明"广告"，具备可识别性。

绝对化用语的执法口径参考市场监管总局《广告绝对化用语执法指南》：客观事实陈述、有合法依据的"首款/首创"、自我比较（"比上一代更轻"）等情形，可不认定违法。**但前提是能拿出依据——拿不出就按红线处理。**

## 涉政府/协会活动宣传的写法规范

这是河南民企类宣传稿最高频的雷区，逐条对照：

| 场景 | 可以写 | 不可以写 |
|---|---|---|
| 参加政府/协会组织的活动 | 受邀出席、参加、参会、参与学习 | 主办、承办、协办、支持单位、联合举办（除非确实是） |
| 现场有领导讲话 | ××在活动中讲话/作主题发布（职务核准） | 领导为我司站台、莅临指导、专门为我司…… |
| 活动主题口号 | 引用时标明是"活动主题" | 直接当企业口号用，不标归属 |
| 合影照片 | 说明为活动合影 | 裁掉活动标识后当作企业活动照 |
| 政府政策 | 引用政策原文并注明文件 | 改写政策原意，或说我司享受"政策倾斜" |

**通用安全句式**：`X 月 X 日，<主办方全称> 主办的 <活动全称> 在 <场地全称> 举行，<我司全称> <职务+姓名> 等受邀出席。`

## 平台侧常见卡点

- 抖音/视频号：口播与字幕中的价格、赠品、限时表述须与实际一致；不得出现"私信领""加微信"等站外引流；使用他人视频素材需授权。
- 小红书：不得虚构使用体验；"种草"类内容涉及商业合作的应标注；不得使用医疗、功效类断言。
- 公众号：转载需注明来源；引用图片版权；"原创"声明不能覆盖他人内容。

## 审核时的三个自问

1. 这句话，如果对方拿着去投诉/举报，我能不能拿出依据？（拿不出 → P0）
2. 这句话，读者会不会误以为是政府/协会在替企业背书？（会 → P0）
3. 这句话，换成一个不认识我们的人读，他会不会觉得在吹？（会 → P1）
