# 视频类稿件专项检查

宣传视频的文案问题，一半在字里，一半在"字和片子对不对得上"。文本审完必须核片。

## 一、字数与时长换算

标准口播语速：正式场合 3.5–4 字/秒，短视频节奏 4.5–5 字/秒。**字幕与口播同步时按 4 字/秒估**。

| 时长 | 3.5 字/秒 | 4 字/秒（默认） | 4.5 字/秒 | 5 字/秒 |
|---|---|---|---|---|
| 15s | 53 | 60 | 68 | 75 |
| 20s | 70 | 80 | 90 | 100 |
| 27s | 95 | 108 | 122 | 135 |
| 30s | 105 | 120 | 135 | 150 |
| 45s | 158 | 180 | 203 | 225 |
| 60s | 210 | 240 | 270 | 300 |
| 90s | 315 | 360 | 405 | 450 |

判断规则：

- 文案字数 > 上限 20% → **D2 扣满**，直接判"口播装不下"，要求删到上限内或延长时长
- 字数在 80%–120% → 正常，注意留出画面呼吸位
- 字数 < 下限 30% → 画面空转，要求补信息点
- 视频无口播、纯字幕+音乐时，可放宽到 6–7 字/秒，但单行不得超过 16 字

## 二、核片流程（拿到成片必做）

```bash
# 1. 拿基本参数：时长、分辨率、有无音轨
ffprobe -hide_banner -show_entries format=duration \
        -show_entries stream=codec_type,width,height \
        -of default=noprint_wrappers=1 <video.mp4>

# 2. 抽帧：开头、每 1/5 处、结尾各一帧
ffmpeg -hide_banner -loglevel error -ss 0.5 -i <video.mp4> -frames:v 1 -vf scale=540:-1 -y f1.jpg
ffmpeg -hide_banner -loglevel error -ss 7   -i <video.mp4> -frames:v 1 -vf scale=540:-1 -y f2.jpg
ffmpeg -hide_banner -loglevel error -ss 14  -i <video.mp4> -frames:v 1 -vf scale=540:-1 -y f3.jpg
ffmpeg -hide_banner -loglevel error -ss 21  -i <video.mp4> -frames:v 1 -vf scale=540:-1 -y f4.jpg
ffmpeg -hide_banner -loglevel error -ss 26.5 -i <video.mp4> -frames:v 1 -vf scale=540:-1 -y f5.jpg

# 3. 逐帧读画面里的字幕，与文本稿逐句比对
```

抽帧后**必须逐字读画面字幕**，与提交的文本稿比对。这一步能抓出文本审完全看不到的问题。

## 三、核片必查的六项

### 1. 字幕与文本稿是否一致（最高频硬伤）
- 人名、职务、名单是否一致（视频写了董事长，文本漏了；文本加了某总经理，视频没有）
- 日期、场地、活动全称是否一致
- 段落顺序、删句是否一致
- 不一致 → **P0**，必须统一口径并说明以哪版为准

### 2. 版式标题与画面主体是否对应
三段式版式（顶部固定标题 + 中部实拍 + 底部字幕）最典型的坑：顶部通栏一直写"我司受邀出席××活动"，中部却放他人演讲、他人合影的特写。观众读到的是"这是我司的活动"。
- 画面主体是第三方时，字幕或角标必须说明其身份（如"××协会秘书长××作主题发布"）
- 顶栏标题与中部画面主体冲突 → **P0**

### 3. 声画与文案是否对得上
- 口播念的与字幕写的不是同一句 → P0
- 文案讲"学习内容"，画面却是空镜/合影 → P1
- 出现未在文案提及的人物特写 → P1（且涉肖像授权，见 A5）

### 4. 结尾落点
- 结尾是主办方口号（"共创美好企业…"），且未标归属、无企业落板 → 观众记不住是谁发的
- 缺企业 logo / 品牌名 / 账号名 → **P1**，建议加 2 秒落板
- 缺下一步动作（关注、进主页、联系）→ P2

### 5. 字幕可读性
- 单行 > 16 字（手机屏读不完）
- 专有名词被断行（"河南省民营企业 / 协会秘书长"这类拆法必须避免）
- 数字连写不利于朗读（"11月6日"可，但口播要念"十一月六日"）
- 字幕压到平台底部 UI 安全区（9:16 竖屏底部留 8%–10%）

### 6. 信息密度
- 信息点数量 ÷ 时长 > 1 个/4 秒 → 观众接不住，要求删点或拆条
- 一条视频只留一个主张，其余降为画面或字幕补充

## 四、给修改意见时怎么算账

不要只说"太长了"。给可执行的三种方案，让用户选：

1. **砍到 27 秒版**：保留哪 108 字（列出来），删掉哪几句
2. **延长到 50 秒版**：补哪几个画面、补哪几句
3. **拆成两条**：第 1 条 15 秒（钩子+关系），第 2 条 30 秒（学习内容+落点）
