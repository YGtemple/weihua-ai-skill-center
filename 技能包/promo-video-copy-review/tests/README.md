# 回归测试与 fixtures

可重复运行：

```bash
python tests/run_regression.py
```

退出码 0 = 全部通过；1 = 有失败项。

## fixtures 来源（两类，性质不同）

**A. 文稿样例 —— 来自真实审稿样例（未编造）：**

| 文件 | 来源 | 预期 |
|---|---|---|
| `S001.txt` | S-001 金秋创新学习活动宣传视频口播/字幕稿（有效字数 199） | `--duration 27.4` 命中 2 处（全新路径、重要力量），超载 62% |
| `S002.txt` | S-002 质量万里行客户走访文本稿（有效字数 60） | `--duration 28.1` 命中 0 处，严重偏少 |
| `negative.txt` | 由 `references/compliance-rules.md` 红线示例短语拼装的对抗样例（唯一/国家级/最佳/第一/政府指定/保证/治愈/加微信） | 命中 8 处 |

**B. 台账统计快照 —— 合成测试数据（非真实台账）：**

| 文件 | 性质 | 预期 |
|---|---|---|
| `ledger-fixture.csv` | **纯虚构记录**：TEST-001/TEST-002、标题"统计回归样例甲/乙"，不含真实稿件标题、企业/活动名、真实核心问题。仅保留验证统计所需的数值（总分 54/62、P0 4/2、是否核片=是） | `--stats-only`：累计 2 篇、平均 58.0、P0 共 6、核片率 100% |

## 数据边界

- 回归脚本只用 `--ledger tests/fixtures/ledger-fixture.csv`（合成数据），**绝不**向真实
  `ledger/审核台账.csv` 追加或修改任何记录；运行前后校验真实台账 SHA256 不变。
- `ledger/审核台账.csv` 是真实业务数据，不随分发包分发；分发包内除表头模板
  `assets/审核台账模板.csv` 外，唯一的 CSV 就是这份合成台账 fixture。
