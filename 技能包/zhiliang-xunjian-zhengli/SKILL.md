# 质量巡检记录整理（zhiliang-xunjian-zhengli）

## Overview

把「多源记录 → 按点位归集 → 异常标色 → 台账输出」串成一条流水线，服务车间月度质量例会和外部审核。核心约束：记录里的数据一律来自用户提供的表与照片，不做合格判定、不改原始数值。

## 硬性规则（违反即失败）

1. 只整理不判定：原记录写「异常」才标异常，模型不自行判断是否合格。
2. 按点位归集：每条记录必须落到具体设备/区域编码上，落不上的单列「点位待确认」。
3. 时间段由用户给定：只整理用户点名的车间与月份，不擅自扩范围。
4. 照片只做归档不识别内容：照片按文件名或用户说明挂到对应点位，不推断画面含义。
5. 缺项显性化：缺记录、缺签字的行留空并写明「待补：XXX」。
6. 结果需人工签字确认后才进正式台账。

## 工作流

1. 读取用户提供的点检表 / Excel / 照片清单，识别表头字段与点位编码。
2. 按车间 + 时间段筛选，其余记录不纳入。
3. 合并同一点位的多次记录，生成一行一条的台账行。
4. 标出异常项与未闭环整改项，附整改单编号。
5. 输出台账 Excel 与异常清单，提示待补项。

## 产出与交付

月度巡检台账（Excel）、异常与整改跟踪表、照片按点位归档目录。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不做设备故障诊断、不做质量判定、不替代质检签字；无点位编码的表先让用户补编码再整理。
