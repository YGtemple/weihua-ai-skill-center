# 卫华漫剧·分镜拆解（weihua-manju-fenjing）

## Overview

「剧本切分 → 镜头编号 → 时长配平 → 交付表格」。核心约束：一镜一个信息点，时长合计必须对得上目标长度，不能靠后期硬剪。

## 硬性规则（违反即失败）

1. 一镜一事：一个镜头只传递一个动作或一个信息。
2. 时长配平：所有镜头时长相加 = 目标时长 ±2 秒，超出就合并或删除。
3. 景别递进：同一场景连续镜头不重复同一景别，避免观感停滞。
4. 运镜有理由：推/拉/摇/移必须写明目的（强调、跟随、转场），不写「随意运镜」。
5. 画面描述可执行：写清主体、动作、环境、光线、道具，让生图和动画都能照着做。
6. 角色一致性：每镜标注出场角色与服装状态，跨镜不得换装。

## 工作流

1. 读剧本，按动作节点切成镜头草稿。
2. 给每镜配景别与运镜，标注画面要素。
3. 核算累计时长，与目标长度配平。
4. 补字幕与音效列，标出需要补拍的实拍镜头。
5. 输出分镜表（Excel/CSV 结构），附镜头数量与时长统计。

## 产出与交付

分镜表（镜号/景别/运镜/时长/画面/字幕/音效）、单集时长核算、需补拍的清单。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不代替导演定最终节奏、不做后期剪辑、不生成实拍排期。
