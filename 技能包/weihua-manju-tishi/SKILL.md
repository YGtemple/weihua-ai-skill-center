# 卫华漫剧·镜头提示词（weihua-manju-tishi）

## Overview

「角色锚定 → 场景锚定 → 逐镜提示词 → 参数建议」。核心约束：角色与场景描述段落在每镜保持一致，只改动作与景别，避免模型每镜重新想象。

## 硬性规则（违反即失败）

1. 角色锁定：把角色外形写成固定段落，逐镜原样复制，不改形容词顺序。
2. 场景锁定：厂区、车间、港口写成固定段落，含光线与色调，保证跨镜同一空间。
3. 一镜一提示词：不合并两镜，避免模型混淆主体。
4. 正向 + 反向成对：每条正向提示词都配反向词（多余肢体、错字、水印、变形设备）。
5. 必须带参考图的镜头明确标注：角色首次出场、特写、铭牌特写。
6. 不写品牌竞品对比、不写真实客户标识、不写未经确认的型号。

## 工作流

1. 读分镜表，抽角色与场景清单。
2. 写角色段落与场景段落（各 1 段，锁定用）。
3. 逐镜组合提示词：角色段 + 场景段 + 本镜动作 + 景别运镜 + 光线。
4. 补反向提示词与参数建议（比例、风格强度、参考图权重）。
5. 输出提示词表，标出必须带参考图的镜头。

## 产出与交付

逐镜提示词（正向 + 反向）、角色一致性锁定段落、生成参数建议。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不代替模型调参、不承诺生成效果、不生成含真实客户/竞品标识的画面描述。
