# 董事长公共风格资产

> **适用范围**：本文件所有风格、句式和语义资产仅适用于卫华集团董事长发言稿。禁止将本文件规则回写、迁移或复用于总裁/总经理发言稿；跨角色经验回写须经独立验证，不得直接套用。

## 一、稳定风格

### 1. 战略判断与经营语言并重

董事长不只是复述经营报表，而是解释数据背后的方向、矛盾与选择。常见推进链为：

> 外部变局 → 行业分化 → 企业处境 → 战略选择 → 全员行动

既有“看清大势”的高度，也有订单、利润、质量、交付、回款、现金流、人才等经营落点。

### 2. 肯定成绩与直面问题并存

成绩讲得具体、提气，问题讲得坦率、准确。既不一味颂扬，也不以批评代替部署。常用辩证关系包括：

- 既要看到优势和机遇，更要正视问题和挑战；
- 越是行业调整期，越要守住质量、利润和长期主义；
- 问题不解决，技术、品牌和团队基础就无法转化为发展成果。

### 3. 战斗感与长期主义相融

紧迫感落在抢订单、保履约、提质量、控成本、抓回款、强团队；长期主义落在技术积累、产品升级、人才梯队、文化根基和共同愿景。避免只有“冲、拼、干”的情绪，没有路径。

### 4. 企业家表达与团队温度相融

尊重奋斗者，关注员工成长、激励兑现和荣誉共享。具体激励、奖金、股权或福利承诺必须有正式依据，不为增强感染力自行加码。

## 二、叙事与句式

### 1. 用概括句统率事实

优先采用“概括句 + 一是/二是/三是 + 事实证据”。概括词必须从本次材料中提炼，事实不足时减少分组，不硬凑三项。

### 2. 长短句交错

- 长句解释形势、因果和战略选择。
- 短句下判断、提要求、收束段落。
- 一段通常只承担一个核心意思；修饰层次过多时拆句。
- 连续排比后，用朴素短句落地，如“方向已经明确，关键在于坚定不移地走下去。”

### 3. 按语义选择逻辑句式

- 判断：“不是……的问题，而是……的问题。”
- 辩证：“既要……，更要……”
- 边界：“既要……，又要……，但绝不……”
- 因果：“这些问题不解决，……就无法……”
- 递进：“不止于……，更在于……”
- 要求：“各级干部要带头……，每一位员工都要……”

这些句式是可选工具，不是每段必用模板。

### 4. 使用自然讲话层级

完整宣读稿使用“第一个方面”“一、”“一是”“第一”等自然层级，同级编号连续且形式一致。不要输出 Markdown 标题，不出现“以下是讲话稿”“本文将从”“综上所述”等生成痕迹。

正式净稿清除“前排领导举例”“这里补充”“可尝试”“临场发挥”等起草括注；确有价值的口语内容改为可直接宣读的正文，没有价值的删除。

## 三、战略语义资产

以下词汇来自既有讲话，只作为可复用语义资产，是否使用以最新正式口径和本次主线为准：

- 战略与愿景：“鹰击长空”“创卓越企业、树百年卫华”“百年卫华”。
- 市场与产品：“中端主流市场”“优势拳头产品”“新、大、特”“高端装备”“海外市场”“起重机+钢结构”。
- 经营与管理：“总成本领先”“高性价比”“降本增效”“提质增效”“现金流”“回款”“积压物资”。
- 客户与履约：“卫华速度”“精品意识”“保履约”“后台服务前台、职能服务业务、全员服务客户”。
- 团队与文化：“厚德、笃行、担当、共赢”“人才是第一资源”“传帮带”“让奋斗者得到褒奖”。

不机械复用年度主题。主题先形成朴素判断，再压缩成简洁分句；压缩后失去事实指向时，宁可保留朴素表达。

“创历史新高”“跨越式增长”“填补空白”“全球首台套”“全面领先”“圆满完成”等强判断必须有直接证据。

## 四、现场表达

### 1. 开场服从会议目的

表彰会突出祝贺和荣誉共享，季度会突出统一认识，半年度会突出承上启下，专项活动突出为什么做和怎么做。领导职务、发言议程、家属或嘉宾出席情况不得猜测。

表彰会的荣誉主线可贯穿开场、复盘、部署和结尾：开场祝贺先进，复盘说明奋斗和价值，部署提出具体学习行动，结尾把荣誉转化为共同再出发的力量。

### 2. 人物与案例服务主线

先进案例采用“任务—行动—结果—精神”的顺序，写清行动和结果，不写成颁奖词合集；没有完整名单或事迹时不虚构姓名、人数和奖项。

### 3. 结尾形成行动与愿景收束

通常回到会议主题、共同信心和下一步行动。诗文、生肖、新春、周年等表达仅在时间匹配且事实准确时使用，避免名句和感叹号堆叠。

## 五、常见偏差

| 偏差 | 修正 |
|---|---|
| 写成部门工作总结 | 用经营判断和能力变化重组事实 |
| 只讲成绩不讲问题 | 写清关键差距及其经营影响 |
| 只讲危机不讲机会 | 补充与企业能力相关的可信机会和信心基础 |
| 部署全是“加强、提升、持续” | 补行动对象、机制、边界或结果指向 |
| 为像董事长而堆满口号 | 用具体判断和事实支撑，每段突出一个核心意思 |
| 把旧稿换年份复用 | 所有事实回到当年材料重新核验 |
| 为统一格式硬凑三部分 | 根据场景和素材调整层次，允许灵活结构 |
| 使用华丽但空泛的 AI 文案 | 改为朴素、直接、可执行的经营语言 |
