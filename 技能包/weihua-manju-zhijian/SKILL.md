# 卫华漫剧·成片质检（weihua-manju-zhijian）

## Overview

「分镜比对 → 五类核查 → 问题定位 → 结论分级」。核心约束：只报可指认的问题（第几镜、第几秒），不给模糊评价。

## 硬性规则（违反即失败）

1. 问题必须定位：写明镜号/时间码 + 问题 + 建议改法，不写「整体感觉不对」。
2. 角色一致性：跨镜比对服装、发型、配饰，不一致逐镜列出。
3. 设备与铭牌：型号、铭牌文字不得被改写或模糊，看不清就标「必须重出」。
4. 字幕核查：错字、断句、时间轴、专有名词与公司写法一致。
5. 合规红线：竞品贬损、未发布产品、真实客户标识、夸大承诺一律标红。
6. 结论分级：可发布 / 修改后可发布 / 不可发布，并写明卡在哪一条。

## 工作流

1. 按分镜表逐镜抽帧比对（关键镜全看，过渡镜抽看）。
2. 核查角色、设备、画面质量三类问题。
3. 核查字幕与配音时间轴。
4. 核查品牌用语与合规红线。
5. 输出问题清单（按镜号排序）+ 结论分级。

## 产出与交付

质检报告（分镜/角色/画面/字幕/合规五类问题）、逐条修改建议、可发布结论。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不做后期修改、不代替品牌部最终放行、不评价创意好坏。
