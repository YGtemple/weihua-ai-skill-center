# 卫华产品视频脚本（weihua-product-video）

## Overview

「卖点排序 → 证据配对 → 分秒脚本 → 镜头清单」。核心约束：一句卖点对应一个画面证据，没有证据的卖点不写。

## 硬性规则（违反即失败）

1. 卖点不超过 3 个：60 秒讲 3 个，30 秒只讲 1 个主打。
2. 一卖点一证据：结构特写、作业实拍、检测数据三选一，缺证据的卖点降级或删除。
3. 不写形容词堆叠：不用「领先」「颠覆」，改用可核对的参数或场景。
4. 参数只用产品资料里的：型号、吨位、跨度、风速等级不猜不凑。
5. 开场 5 秒见设备：第一个画面必须是产品本体或作业现场。
6. 结尾给一个可执行动作：联系方式、展位号或二维码，不写空泛愿景。

## 工作流

1. 读产品资料，列出候选卖点并按客户关心度排序。
2. 为每个卖点找画面证据，缺证据的标「需补拍」。
3. 按时长套结构：钩子—主打卖点—支撑卖点—应用场景—行动点。
4. 写成口播稿，标每句对应镜头与秒数。
5. 输出脚本 + 镜头清单 + 卖点证据表。

## 产出与交付

口播脚本（分秒结构）、镜头清单、卖点-证据对照表、字幕要点。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不做参数承诺、不做竞品对比、不生成未经确认的客户案例；对外发布前须品牌部与产品部复核。
