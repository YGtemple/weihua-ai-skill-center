# 询比价汇总对比（xunbijia-huizong-duibi）

## Overview

「口径确认 → 报价拆项 → 换算到基准 → 差异标注 → 比价表」五步。核心约束：口径由用户先定，换算公式与税率写进表里可复核，模型不做商务决策。

## 硬性规则（违反即失败）

1. 先定口径再算价：口径没给全就先问，不默认含税或默认包运费。
2. 换算留痕：每家的原始价、税率、运费、换算后基准价四列都要在表里。
3. 规格差异单列：规格不一致的项不强行同列比较，标注「规格不同，不可直接比」。
4. 不替用户定标：只给推荐顺序和理由，最终由采购决策。
5. 报价单是照片时只转录用户可确认的数字，模糊处留空并标注待核。
6. 金额单位统一为元，保留两位小数。

## 工作流

1. 读取各家报价单，抽出物料名称、规格、单价、税率、运费、账期。
2. 按用户口径换算：不含税价 = 含税价 /（1 + 税率）；到厂价 = 不含税价 + 运费分摊。
3. 同一物料合并为一行，各家报价格并排。
4. 标注规格差异、缺项、明显异常价（高于均价 30% 以上）。
5. 输出比价表 + 推荐顺序 + 差异说明。

## 产出与交付

比价汇总表（含税与不含税两列价）、规格差异说明、推荐顺序与理由。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不签合同、不做供应商准入评审、不代替采购谈判；报价真伪由采购核原件。
