# 页面字段同义词与映射细则

## 一、企业基础信息

| 页面常见写法 | 基础信息表字段 | 备注 |
|---|---|---|
| 单位名称、供方名称、企业名称、公司名称、投标人名称、供应商名称、注册名称 | 公司全称 | 必须与营业执照一致，不加空格 |
| 统一社会信用代码、信用代码、纳税人识别号、税号、社会信用代码 | 统一社会信用代码 | 18 位，大写字母 |
| 法定代表人、法人、法人代表、法定代表人姓名 | 法定代表人 | 不要与"法人身份证号"混淆 |
| 注册地址、公司地址、住所、注册地 | 注册地址 | 与"实际经营地址"不一致时才需确认 |
| 实际经营地址、办公地址、通讯地址 | 实际经营地址 | 无该字段时回落到注册地址 |
| 邮政编码、邮编 | 邮政编码 | |
| 企业类型、企业性质、公司类型、经济性质 | 企业性质 | 见"选项归类" |
| 注册资本、注册资金 | 注册资本 | 保留原单位（万元），页面要求纯数字时去单位 |
| 成立日期、成立时间、注册日期 | 成立日期 | 转 `YYYY-MM-DD` |
| 营业期限、经营期限 | 营业期限 | 含"长期"时按页面要求填"长期"或留空 |
| 所属行业、行业类别 | 所属行业 | |
| 经营范围、主营范围 | 经营范围 | 长文本，注意页面字数限制，超限时截断到分号前的完整项 |
| 员工人数、职工人数、从业人员 | 员工人数 / 公司总人数 | |
| 公司网址、网站 | 网址 | |
| 英文名称、英文名 | 英文名 | |

## 四、授权信息

| 页面字段 | 处理方式 |
|---|---|
| 授权人、授权代表、法定代表人授权 | 优先取清单内授权委托书信息；无则向用户索取 |
| 被授权人、被授权人身份证号、被授权人电话 | 同上，不自行编造 |
| 授权期限 | 按授权委托书内容填写；无文件时留空并标注 |

## 五、选项归类

页面下拉选项与表格文字不完全一致时，按语义归入最接近的选项，并在报告中标注归类动作。

| 表格值 | 常见页面选项 | 建议归类 |
|---|---|---|
| 其他有限责任公司 | 有限责任公司 / 股份有限公司 / 个体工商户 | 有限责任公司 |
| 有限责任公司（自然人投资或控股） | 同上 | 有限责任公司 |
| 制造业 | 制造业 / 工业 / 生产制造 | 制造业 |
| 是 / 否（定制化能力等） | 是 / 否 | 直填 |

## 六、拿不准就停

以下情形标记【人工核对】并留空，不猜测：

- 页面字段与表格字段只是字面相近但含义不同（如"注册资本"与"实缴资金"、"合同金额"与"年销售额"）
- 页面要求填写表格中不存在的字段（如"上年度纳税额""社保缴纳人数明细""银行资信等级"）
- 同一字段在表格中存在多个不同值且无法判断口径
