# 执行汇总报告模板

报告在"暂停、等待用户确认"时输出。用户不看中间过程也应能读懂：填了什么、传了什么、缺什么、下一步做什么。

```markdown
## 供应商注册填报执行报告

**目标平台**：{平台名称}  {网址}
**执行时间**：{YYYY-MM-DD HH:MM}
**资料源**：{资料库根目录}
**当前状态**：表单已填写完成，未提交，等待确认

---

### ✅ 已填写字段

| 页面字段 | 填入值 |
|---|---|
| 单位名称 | … |
| 统一社会信用代码 | … |
| 法定代表人 | … |
| 注册地址 | … |
| 联系人 / 联系电话 / 邮箱 | … |
| 开户行 / 银行账号 / 开票名称 | … |

（字段较多时按页面分段列，保持"页面字段 → 填入值"两列，便于逐行核对）

### ✅ 已上传资质与有效期

| 页面控件 | 上传文件 | 有效期 |
|---|---|---|
| 营业执照 | 营业执照.jpg | 2029-03-17 / 长期 / 留空 |
| … | … | … |

### ⚠️ 资质缺失

| 缺失项 | 检索范围 | 页面是否必填 | 处理 |
|---|---|---|---|
| 承诺书 | 两份清单均无对应文件 | 未标注必填 | 未上传，控件保持空 |

（若清单标注【暂缺】但目录中存在同名文件，此处标注"清单标注暂缺，实际文件存在，待用户确认是否启用"）

### 📝 待人工核对

1. {具体项}：{原因}，{建议动作}
2. 例如：营业执照有效期 —— 清单无到期日、页面为日期控件，已留空，请提供准确到期日
3. 例如：企业类型 —— 表格为"其他有限责任公司"，下拉无此项，已归入"有限责任公司"

### 🔻 下一步

- 请在浏览器中核对上述内容。
- 确认无误后回复"确认提交"，由我点击提交；需要修改请直接指出字段名。
- 本次自动化无法完成的步骤：{短信验证码 / 图形验证码 / 协议勾选 / 电子签章}
```

## 附：技术说明（当使用本地承载页时必写）

```markdown
**执行方式说明**：目标为本地 HTML 表单（无真实站点），已用本地 http 服务承载原文件（未修改原文件），
文件上传与日期字段由页面脚本注入（Windows 文件选择框与 date 控件无法用键鼠驱动）。
服务地址 http://127.0.0.1:{port}，关闭方式：结束对应后台进程。
```
