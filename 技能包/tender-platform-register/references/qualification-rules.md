# 资质清单结构、有效期口径与缺失处理

## 一、资质清单.xlsx 实际结构

单子表 `资质清单`，四列：

| 列 | 含义 | 示例 |
|---|---|---|
| A 类别 | 资质大类 | 营业执照 / 特种设备生产许可 / 质量管理体系认证 |
| B 证书完整名称 | 证书全称，常用于与页面控件名匹配 | 中华人民共和国特种设备生产许可证（副本） |
| C 文件路径 | **资料库内相对路径**，相对根目录 `E:\卫华供应商入围资料库` | `资质文件\营业执照.jpg` |
| D 状态 | 有效 / 暂缺 / 过期 | 有效 |

**注意：该表没有"有效期"列。** 有效期需从基础信息表取，见第三节。

## 二、供应商入围资料清单.xlsx 实际结构

单子表 `供应商入围资料清单`，五列：

| 列 | 含义 |
|---|---|
| A 文件名 | 含后缀的文件名 |
| B 文件完整路径 | 绝对路径 |
| C 文件后缀 | pdf / jpg / png / docx / xlsx / pptx / xls |
| D 文件大小(KB) | 用于校验文件是否为占位空文件（<10KB 需警惕） |
| E 备注 | 特殊要求，优先级最高 |

已知数据质量问题：

1. 个别行 B 列路径丢失文件名（形如 `...\供应商入围资料\.docx`）。
2. 资料库曾被整体重组：`供应商入围资料\` 下原本的 docx / xlsx / jpg / png 有一批被同名的 **pdf** 版本替代（同一基础名，扩展名变化），原文件已不在该目录。

处理方式：

| 情形 | 判定 | 动作 |
|---|---|---|
| 路径中缺文件名 | `same_dir_name` | 同目录按 A 列文件名查找 |
| 文件被移到其他子目录 | `moved_same_name` | 全库同名检索 |
| 仅扩展名变化（同名不同格式） | `fuzzy_unique` + `ext_changed` | 上传前核对页面 accept；图片类控件不接受 PDF 时不下传，标【格式不符：需人工转换】 |
| 模糊命中多条 | `fuzzy_ambiguous` | 列为候选，交人工确认，不自动选 |
| 完全无命中 | 缺失 | 标 `【资质缺失：XXX】`，控件留空 |

以上补正结果只写入缓存 JSON 与报告，不回写 Excel。

## 三、有效期取值口径

基础信息表"二、经营与资质信息"段含证书编号、有效期、发证单位三类信息，有效期原文形如 `2026年3月18日至2029年3月17日`，取**截止日期**并转 `YYYY-MM-DD`。

| 证书 | 有效期来源 | 是否必填 |
|---|---|---|
| 质量管理体系认证（ISO9001） | 基础信息表 | 是 |
| 环境管理体系认证（ISO14001） | 基础信息表 | 是 |
| 职业健康安全管理体系认证（ISO45001） | 基础信息表 | 是 |
| 建筑业企业资质（起重设备安装） | 基础信息表 | 是 |
| 特种设备生产许可证（起重机械） | 基础信息表 | 是 |
| 安全生产许可证 | 基础信息表 | 是 |
| 营业执照 | 无到期日（营业期限为长期） | 见下 |
| 高新技术企业证书 | 两张表均无 | 见下 |
| 基本存款账户信息 / 开户许可 | 无到期日 | 见下 |
| 增值税一般纳税人证明 | 无到期日 | 见下 |
| 信用截图、现场照片、业绩合同、财务报表 | 无到期日 | 见下 |

"见下"类处理：

1. 页面是文本框 → 填"长期"（页面有"无""不适用"选项时优先选选项）。
2. 页面是 `date` 控件 → 留空，写入报告"待人工核对"，请用户补准确日期。**不要**用任意日期占位，日期错填会导致资质被判无效。

## 五、缺失处理标准动作

1. 命中缺失 → 该控件保持"未选择文件"，不注入空文件、不注入 `0 字节` 占位。
2. 报告中单列 `⚠️ 资质缺失`，写明缺失项名称与检索范围（两份清单均无 / 清单有但文件不存在）。
3. 若页面把该控件标为必填，在"待人工核对"中提示用户补件或联系平台确认豁免。
4. 同类多文件只上传一张时（如 6 张信用截图），把未上传的列入"未上传备选"，便于用户按平台要求替换。
