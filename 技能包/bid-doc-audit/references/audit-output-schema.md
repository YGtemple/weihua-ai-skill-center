# 报名资料合规审核报告 Excel 结构定义（v1.5 升级）

> **v1.5 增量**：
> 1. 主报告"⚠️ 人工必复核项"由六分类升级为**七分类**，新增 **📷 截图类资料人工必复核** 类别；
> 2. 独立 sheet「人工资料完整性核对对照表」新增**截图类资料页面锚点识别线索分块**；
> 3. 后附扫描窗口超出提示统一为"附件超出扫描窗口，请人工继续翻阅PDF后续页面核对"。

## 文件命名

- 主文件：`报名资料合规审核报告.xlsx`
- 输出目录：`<工作区>/报名审核输出/<项目名或YYYYMMDD>/`

## Sheet 顺序（强制）

| # | Sheet 名 | 类型 | 说明 |
|---|---|---|---|
| 1 | `合规审核报告` | 主报告 | 强制兜底声明置顶 + 项目基本信息 + 5 大板块 |
| 2 | `人工资料完整性核对对照表` | 独立 sheet | v1.4 升级：存放 PDF 后附扫描线索与告警 |

> 其他 sheet 可按需添加，但**至少包含以上两个 sheet**。

## 主 Sheet「合规审核报告」结构

### 1.1 强制兜底声明（第 1 行）

```
【强制兜底声明】本AI审核仅为辅助参考，存在识别盲区与匹配误差，务必区分【报名递交资料】【投标递交资料】【现场备查】【中标后提交】，所有资料、资质、有效期、报名要求务必人工对照公告原件及证书原件二次复核，确认无误后方可提交。
```

- 字体：粗体 + 红色 (`color="9C0006"`)；
- 填充：浅红色 (`fgColor="FFC7CE"`)；
- 跨列合并 6 列；行高 48 像素。

### 1.2 项目基本信息（第 3 行起）

| 字段 | 取值 |
|---|---|
| 项目名称 | 公告中项目名 |
| 审核依据-公告 | 公告文件名 |
| 审核依据-汇总表 | 来自【招标公告智能标记解析】汇总表 / 直接解析原始招标公告（模式B时） |
| 审核依据-数据源 | CA登记表.xlsx / 重点平台清单.xlsx（本地权威数据源，只读）+ 公告原文 |
| 我方报名资料 | 文件夹路径或文件列表描述 |
| 我方投标资料 | 文件夹路径或文件列表描述 |
| 审核时间 | 当前时间 yyyy-MM-dd HH:mm |
| 模式 | `模式A（汇总表）` / `模式B（直接解析公告，存在识别偏差风险）` |

### 1.5 三、⚠️ 人工必复核项（**强制七分类**）

| 类别 | 条目 | 原文要求 | 建议核对方式 |
|---|---|---|---|

七分类：

1. 🟩 现场备查
2. 🟨 中标后才需要
3. 🟥 阶段存疑
4. 📌 后附扫描线索（v1.4；摘要列出，详细看 Sheet 2）
5. 📌 平台合规无清单佐证
6. 📌 CA/资质即将过期（≤90 天）
7. 📷 **截图类资料人工必复核**（v1.5 新增）——针对营业执照、中国执行信息公开网、信用中国网页截图等图片/截图形式提交的证明资料

> **📷 截图类资料人工必复核** 类别下条目强制使用以下标准提示模板：
  - 锚点命中时：「已检测到对应资料页面；页面内容为图片/截图，无法读取图片内部文字，请人工复核：资料主体单位是否为本单位、证书/截图时间、有效期是否满足招标要求」
  - 锚点未命中时：「未检索到资料页面锚点关键词，请人工打开 PDF 确认是否已附上该资料，资料为图片截图时文本层无法识别」

## 独立 Sheet「人工资料完整性核对对照表」结构（v1.4 强制 + v1.5 升级）

### 基础分块：PDF 后附扫描线索（v1.4）

| 字段 | 必填 | 说明 |
|---|---|---|
| 序号 | ✅ | 1, 2, 3 ... |
| PDF 文件名 | ✅ | 命中的报名 PDF 名称 |
| PDF 总页数 | ✅ | 该 PDF 的总页数 |
| 命中关键词 | ✅ | 财务/审计/社保类关键词原文 |
| 后附标注所在页 | ✅ | 命中所在页（从 1 开始） |
| 5 页窗口扫描范围 | ✅ | `第N+1页 ~ 第min(N+5, 总页数)页` |
| 结果分类 | ✅ | `✅ 检索到附件线索` / `⚠️ 风险提醒` / `📷 扫描PDF无法识别` |
| 命中附件线索 | 结果①时必填 | 命中的附件线索关键词列表 |
| 备注 | ✅ | 见 `houfu-scan-rules.md` 第 4 节备注栏文案 |
| 建议 | 结果②/③时必填 | "人工打开PDF自查第N+6页及之后" / "人工逐页检查PDF是否插入相应附件" |

### 升级分块：截图类资料页面锚点识别线索（v1.5 新增）

| 字段 | 必填 | 说明 |
|---|---|---|
| 序号 | ✅ | 续编号（与上分块连续） |
| 资料类型 | ✅ | "营业执照" / "中国执行信息公开网截图" / "信用中国截图" 等 |
| PDF 文件名 | ✅ | 命中的报名 PDF 名称 |
| 锚点命中情况 | ✅ | `✅ 已检测到资料页面（图片/截图）` / `⚠️ 未检索到锚点关键词` / `📷 PDF 文本提取为空（疑似整本扫描件）` |
| 命中关键词 | 路径 A 时必填 | 命中的锚点关键词原文 |
| 命中页码 | 路径 A 时必填 | 锚点所在页码（从 1 开始） |
| 备注 | ✅ | 路径 A/B 标准提示（见 `screenshot-proof-rules.md` 第 3 节） |
| 建议核对方式 | ✅ | "人工打开PDF第N页复核图片内容" / "人工逐页翻阅PDF确认" |
