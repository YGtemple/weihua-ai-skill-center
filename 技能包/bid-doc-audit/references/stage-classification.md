# 递交阶段分类规则（v1.4）

本文件定义【投标人需准备资料清单】中"递交阶段"字段的所有可能取值，以及在审核时**每一类条目应被如何处理**。

## 1. 五类阶段枚举值（与上游【招标公告智能标记解析】模块【投标人需准备资料清单】工作表保持一致）

| 图标 | 阶段文字（汇总表 cell 原样） | 触发处理动作 | 是否计入 ❌ 漏项 |
|---|---|---|---|
| 🟪 | `报名环节递交` | 全六维审核（漏项/错项/有效期/平台合规/格式/命名） | ✅ 计入 ❌【报名漏项】 |
| 🟦 | `投标文件递交` | 全六维审核 | ✅ 计入 ❌【投标漏项】 |
| 🟩 | `开标/评标现场备查，不需随报名/投标递交` | **不判定缺失**，移入 ⚠️ 人工必复核，写明"现场备查" | ❌ 不计入 ❌ |
| 🟨 | `中标后才提供，本次报名投标均无需准备` | **完全不做缺失校验**，移入 ⚠️ 人工必复核，写明"中标后" | ❌ 不计入 ❌ |
| 🟥 | `递交阶段‑存疑‑需人工阅读原文确认` | 全部归入 ⚠️ 人工必复核，禁止私自判定 | ❌ 不计入 ❌ |

## 2. 阶段文字匹配规则（用于从汇总表 cell 读取图标 + 文字）

优先匹配精确前缀：

```
🟪 报名环节递交
🟦 投标文件递交
🟩 开标/评标现场备查，不需随报名/投标递交
🟨 中标后才提供，本次报名投标均无需准备
🟥 递交阶段‑存疑‑需人工阅读原文确认
```

若 cell 文本中没有以上五个前缀，则按 cell 文本中**包含的关键字**判定：

| 关键字 | 归类 |
|---|---|
| `报名`、`报名环节`、`资格预审` | 🟪 |
| `投标`、`投标文件`、`投标递交` | 🟦 |
| `现场`、`开标`、`备查`、`原件备查`、`评标现场` | 🟩 |
| `中标后`、`中标后提供`、`中标后提交` | 🟨 |
| `存疑`、`待确认`、`?`、`？`、`需人工阅读` | 🟥 |

## 3. ❌ 错误/缺失项 强制四分类

报告板块二（❌ 错误/缺失项）按下列**强制四列分组**输出：

| 子标签 | 含义 |
|---|---|
| ❌【报名漏项】 | 🟪 条目，未在我方报名资料中找到 |
| ❌【报名错误】 | 🟪 条目，存在但类型/专业/范围不匹配、格式不达标、命名不规范等 |
| ❌【投标漏项】 | 🟦 条目，未在我方投标资料中找到 |
| ❌【投标错误】 | 🟦 条目，存在但不匹配 |

每条强制字段：

| 字段 | 必填 | 示例 |
|---|---|---|
| 项目 | ✅ | 安全生产许可证 |
| 子标签 | ✅ | ❌【报名漏项】 |
| 公告原文依据 | ✅ | "投标人须知第 3.2 条：…（原文页码 X / 段号 Y）" |
| 问题描述 | ✅ | 我方报名资料文件夹中未找到此证 |
| 修改/补充建议 | ✅ | 取得安全生产许可证原件后扫描、上传 |

## 4. ⚠️ 人工必复核项 五类来源

报告板块三（⚠️ 人工必复核项）汇总以下五类条目，**全部不计入 ❌ 计数**：

1. 🟩 开标/评标现场备查资料（现场携带原件，**不需随报名/投标上传**）
2. 🟨 中标后才需要的资料（中标后提交，**本次报名投标不用准备**）
3. 🟥 阶段存疑资料（需打开公告原文人工核对）
4. 📌 PDF 后附扫描线索与风险提醒（独立工作表【人工资料完整性核对对照表】中也有，本表同步摘要列出）
5. 平台合规无清单佐证的异常
6. CA / 资质即将过期（≤ 90 天）的临界警告

每条强制字段：

| 字段 | 必填 | 示例 |
|---|---|---|
| 条目 | ✅ | 法定代表人身份证原件 |
| 类别 | ✅ | 🟩 现场备查 |
| 原文要求 | ✅ | "开标时核验法定代表人身份证原件"（公告第 5 页） |
| 建议核对方式 | ✅ | 报名、投标环节不用上传，开标当日随身携带原件到场 |

## 5. 兜底（防错规则）

- 若阶段 cell 既没有图标也没有识别关键字 → 默认按 🟥 存疑处理，禁止猜测归类为 🟪/🟦/🟩/🟨。
- 若某条目阶段正确读取但公告未提供 → 必须 ⚠️ 人工必复核，禁止写 ❌【报名漏项】/❌【投标漏项】。
