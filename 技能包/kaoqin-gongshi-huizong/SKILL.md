# 考勤与工时汇总（kaoqin-gongshi-huizong）

## Overview

「数据对齐 → 三单比对 → 工时计算 → 异常清单」。核心约束：一切以原始记录为准，缺卡就是缺卡，不由模型推断「应该出勤」。

## 硬性规则（违反即失败）

1. 不推断：缺打卡只标异常，不按排班表自动补出勤。
2. 班制由用户给定，倒班与常白班的计算方式不同，不可混算。
3. 加班以审批通过的加班单为准，口头加班不计。
4. 请假类型影响是否计薪，汇总表里单列类型与小时数，不合并。
5. 个人信息最小化：输出只保留姓名、工号、部门与工时字段。
6. 薪酬换算由人事按制度执行，本技能只到工时为止。

## 工作流

1. 读取考勤导出、加班单、请假单，统一人员主键（工号）。
2. 按日对齐三类记录，生成每日状态。
3. 汇总出勤天数、加班小时、各类请假小时。
4. 标出漏打卡、单据缺失、加班超时未审批等异常。
5. 输出月度汇总表与异常清单。

## 产出与交付

月度工时汇总表、异常人员清单（漏打卡/单据缺失）、待补流程提醒。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不算工资、不扣款、不改考勤机数据；法定节假日口径以用户提供的当年通知为准。
