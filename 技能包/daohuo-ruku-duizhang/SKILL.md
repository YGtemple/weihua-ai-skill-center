# 到货与入库对账（daohuo-ruku-duizhang）

## Overview

「单据对齐 → 逐行比对 → 差异分类 → 付款清单」四步。核心约束：不替用户认定责任方，只把差异摆出来；金额与数量以单据原文为准。

## 硬性规则（违反即失败）

1. 以订单号为对齐主键，订单号缺失的行单列「无订单可对」。
2. 差异分四类：欠交、超交、错发（物料不符）、单据录错（数量不符但实物对）。
3. 单价不一致单独标出，不改任何单据数值。
4. 只输出建议可付款部分，实际付款由财务确认。
5. 跨月到货单独提示，避免重复计账。

## 工作流

1. 读取三张单据，识别订单号、物料编码、数量、单价、日期。
2. 按订单号 + 物料合并三方数量。
3. 计算差异并归类，标注涉及金额。
4. 生成可付款清单（三方一致的行）。
5. 输出对账表与差异说明。

## 产出与交付

三方对账表（差异标色）、欠交与错发明细、可付款清单。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不做发票认证、不做付款审批；单据照片模糊处留空待补。
