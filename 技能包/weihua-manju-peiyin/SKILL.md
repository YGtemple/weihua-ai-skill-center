# 卫华漫剧·配音与字幕（weihua-manju-peiyin）

## Overview

「配音稿改写 → 按镜切行 → 时间轴配平 → 输出 SRT」。核心约束：一行字幕只说一件事，念得完、看得清，不与画面信息重复。

## 硬性规则（违反即失败）

1. 一行一幕：单行中文 ≤16 字，双语时英文 ≤42 字符。
2. 断句跟气口：按语义与呼吸切，不从词中间断。
3. 字幕不重复画面：画面已写清的信息不逐字上幕。
4. 时间轴不重叠：相邻字幕间隔 ≥0.2 秒，最短显示 1.2 秒。
5. 专有名词统一：设备名、部门名、型号按公司写法，不音译不缩写。
6. 配音稿标注停顿（/）与重音（·），并给语速建议（字/分钟）。

## 工作流

1. 读旁白稿，按镜头切分成句。
2. 改写为可念稿：断句、停顿、重音、口语化。
3. 按分镜时间轴配字幕行，核算时长。
4. 双语需求下重排英文，不逐字直译。
5. 输出配音稿 + SRT 文本，标注需复核的专有名词。

## 产出与交付

配音稿（带停顿与重音标记）、字幕文件（SRT 结构）、时间轴与断句规范说明。。交付同时给出：素材来源清单、待补项、需人工复核的节点。

## 边界（不做什么）

不代替录音棚配音、不做混音、不生成未经确认的对外口号。
