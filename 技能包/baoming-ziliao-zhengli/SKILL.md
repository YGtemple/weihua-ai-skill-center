# 报名资料自动整理（baoming-ziliao-zhengli）

## Overview

将「招标公告 → 报名必传资料清单 → 台账调取 → 文书填充 → Word 汇总 → 核对台账」串成一条可复用流水线，服务起重机械/重型机械企业（河南区域）在各类招标平台上的报名投递。

核心约束：**只读取本地资料库与台账，不编造任何公司信息、证书编号、业绩数据**。取不到的文件用红字提示缺件，不猜、不补、不近似。

## 硬性规则（违反即失败）

1. **数据只来自本地**：主体信息、人员证件、业绩、证书均须可回溯到资料库文件或台账某行；关键数据应能指出出处（文件路径 + 位置）。
2. **清单驱动**：先解析招标公告得出必传清单，再按清单归集。**公告未列明的资料一律不纳入**（公告未要求厂区照片、财务报表，就不放进报名包）。
3. **区分两类要求**：公告中的资格条款（独立法人、不接受联合体、CA 证书、资格后审等）只做台账说明，不生成文书、不占报名包。
4. **业绩不自选**：需要哪些业绩必须由用户点名，禁止自行挑选业绩文件。
5. **模板优先**：存在甲方模板则用甲方模板；无甲方模板时用公司自有模板（`模板库/` 或本轮指定目录）；模板原有字号、对齐、落款结构一律保留，只替换需填写的段落文字。
6. **缺件显性化**：缺谁、缺哪一面、缺哪个字段，都在正文对应位置红字写明「【缺失：XXX，请补充文件】」，不隐藏、不降级为"已备齐"。
7. **主体一致性校验**：图片类佐证必须核对图内主体名称与本次投标主体是否一致；不一致或为打码样张时红字告警并标注"仅演示版式，正式报名须替换"。
8. **交付前提示人工复核**：文书需盖章签字、图片需换原件扫描件、平台需人工上传。

## 工作流

### 第 1 步：解析招标公告

- PDF 用 `workbuddy-pdf` 本地 CLI 提取文本；Word 直接读。
- 提取要素：项目名称、项目编号、招标人、招标代理机构、报名/递交时间、平台地址、资格要求条款、报名上传资料条款（通常位于「招标文件的获取」）。
- 判断招标代理机构是否存在：**有则授权委托书抬头写两行（致代理机构 / 致招标人），无则只写致招标人**。
- 输出《本次报名必填资料清单》（Markdown：序号 / 资料名称 / 公告依据条款 / 格式 / 本地是否有件 / 状态）。

### 第 2 步：读取台账与配置

| 文件 | 用途 |
|---|---|
| `报名资料清单.xlsx` | 资料名称 → 文件存放路径（第 5 列），按路径取件 |
| `授权人员台账.xlsx` | 姓名 → 身份证号 / 联系方式，被授权人优先从此表取 |
| `00-SKILL配置/公司信息*.json` | 单位名称、统一社会信用代码、法人、地址、电话 |

- 台账路径常见瑕疵：只写到目录、缺扩展名、登记名与实际文件名不一致。先跑 `scripts/check_ledger.py` 批量比对，再按目录内实际文件校正，**并在清单中注明"登记名 → 实际文件"**。
- 台账查不到的临时被授权人：暂停流程，等用户提供姓名、身份证号、身份证正反面图片后再继续。

### 第 3 步：归集佐证资料

按清单逐项取件并核对内容（图片必须实际看图确认，不能只看文件名）：

- 营业执照（加载统一社会信用代码）
- 资质证书、体系认证（ISO9001/14001/45001、矿用产品安全标志等）、荣誉证书
- 人员证书（建造师、安全员、特种作业等）
- 信用类截图（中国执行信息公开网、信用中国严重失信主体名单、中国裁判文书网行贿罪）
- 社保参保证明、财务报表、纳税证明
- 厂区/设备照片（仅当公告要求时）

### 第 4 步：业绩梳理与核对

按 `references/业绩核对规则.md` 执行：逐份业绩提取使用单位、总包单位、合同金额、签订时间、设备规格型号，核对与本次招标的匹配度，输出业绩台账（可投标 / 需补证 / 不可用）。

### 第 5 步：生成文书与汇总 Word

- 文书：在公司模板原件上填充（`scripts/template_fill.py`，支持段落替换 + 按标签插图片），落款日期用任务当天，授权有效期默认当日起一个月。
- 汇总文档结构：首页标题与项目要素 → 目录（带状态标注）→ 按清单顺序的正文（文书直写、图片直插）→ 报名资料核对台账（带表头表格）。
- 排版：A4、标准页边距、正文宋体/仿宋小四、每类资料用「标题2」分节。用 `scripts/docxgen.py` 生成，无需第三方库。

### 第 6 步：交付与复核提示

输出后必须说明：本文档包含哪些资料、哪些 PDF 需人工另附、哪些缺件待补、哪些图片主体不符需替换，并提醒人工复核后上传。

## 脚本

| 脚本 | 用途 |
|---|---|
| `scripts/readx.py` | 无依赖读取 xlsx / docx（zip + XML），输出二维表与段落文本 |
| `scripts/docxgen.py` | 无依赖生成 docx：A4、宋体小四、标题2、带边框表格、图片等比缩放、红字标注 |
| `scripts/template_fill.py` | 在模板 docx 上按段落文字填充、按标签插入图片（自动写 media/rels/Content_Types） |
| `scripts/check_ledger.py` | 校验台账登记路径是否真实存在，列出"登记名 vs 实际文件"差异清单 |

环境无 openpyxl / python-docx / pdftotext 时以上脚本仍可运行（仅依赖标准库）；PDF 文本提取用 `workbuddy-pdf` 本地 CLI。

## 常见坑

- 台账登记「全员参保证明.pdf」而实际是 `全员社保.docx`（内嵌扫描页）——按实存文件取，并注明差异。
- 图片类资料先看内容再入库：打码样张、别家公司截图、空白入口页都不能当有效证明。
- 身份证图片常见问题：只有人像面、带「演示样例」水印、卡面号码与台账号码不一致——三处都要在文档中标注。
- 模板换版后段落序号会变，一律按文字定位段落，不写死索引。
- 目标 docx 被预览面板占用会写入失败（PermissionError），保存时按 `-新/-v2/-v3` 依次回退并在交付说明中指出。

## 附录 A：资料七大类别与校验要点

| 类别 | 典型资料 | 校验要点 |
|---|---|---|
| 主体资格 | 营业执照、开户许可证、法人身份证明、授权委托书 | 经营范围含起重机械制造/安装；执照在有效期且含最新年检页；统一社会信用代码与台账一致 |
| 资质证书 | 特种设备制造许可证（起重机械 A/B 级）、安装改造维修许可证、安全生产许可证、型式试验证书 | 许可子项覆盖投标设备型谱；有效期覆盖投标与履约期；型号与投标型号逐一对应 |
| 体系认证 | ISO9001、ISO14001、ISO45001、测量管理体系、售后服务认证 | 认证范围含起重机械设计制造；在有效期内且可官网核验 |
| 业绩 | 合同、中标通知书、验收单/用户证明、发票 | 使用单位与总包关系清楚；近三年；金额、吨位、跨度达标 |
| 荣誉 | 高新技术企业、专精特新、驰名商标、优质工程/用户满意证书 | 与公告加分条款一一对应；注意发证机构层级 |
| 财务与信用 | 近三年审计报告、纳税证明、社保参保证明、信用中国/执行信息公开网/裁判文书网截图 | 报告期完整；截图须含查询日期与完整 URL |
| 人员与其他 | 建造师/安全员/特种作业证、CA 数字证书、保证金凭证 | 社保缴纳单位为本企业；CA 在有效期内 |

## 附录 B：投标资料台账字段规范

输出《投标资料台账》时按以下列顺序，缺值一律写「待补」，不得留空：

序号 / 资料类别 / 资料名称 / 公告依据条款 / 是否强制 / 提交形式 / 份数 / 证书或合同编号 / 发证机关或甲方 / 有效期至 / 业绩使用单位 / 总包单位 / 项目名称 / 合同金额(万元) / 供货或验收时间 / 文件路径或页码 / 状态 / 备注

状态取值固定为六类：`齐备`、`待补`、`需更新`、`需盖章`、`信息不一致`、`待人工处理`。

配套输出《缺失与补正清单》，字段：序号 / 缺失或问题描述 / 影响条款 / 责任部门或责任人 / 建议完成时间 / 处理状态。

## 附录 C：河南重工类投标场景要点

1. 平台多为河南省公共资源交易中心、河南重工电子采购平台，常见「线上上传 + 纸质邮寄」双轨，电子件按平台限页限大小拆分，纸质件加盖公章与骑缝章。
2. 业绩口径多为「近三年同类起重设备供货业绩」，接受总包业绩但须附总包与业主关系说明；吨位、跨度不得低于公告要求。
3. 加分项（高新、专精特新、三体系、省级以上荣誉）单独成页并标注对应条款，便于评委核对。
4. 高频退件原因前置排查：执照过期缺年检页、授权委托书未按项目单独出具、业绩合同缺验收证明、信用截图无查询日期、复印件未盖章。
