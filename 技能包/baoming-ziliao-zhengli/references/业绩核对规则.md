# 业绩核对规则

## 1. 逐份业绩必取字段

从业绩合同/中标通知书/验收证明/发票中提取（缺项标「未见」）：

| 字段 | 说明 |
|---|---|
| 合同名称 | 合同封面原文 |
| 使用单位 | 招标人/发包人全称（**不是**总包单位） |
| 总包单位 | 若为分包合同，写明总包；无总包写「直签」 |
| 最终用户 | 设备实际使用方，与使用单位可能不同 |
| 合同金额 | 含税/不含税要注明 |
| 签订时间 | 年-月-日 |
| 设备名称/规格型号 | 起重量、跨度、工作级别（如 QD50/10t-22.5m A5） |
| 供货范围 | 整机/改造/配件 |
| 佐证材料 | 合同、发票、验收单、中标通知书分别有无 |

## 2. 与本次招标的匹配判定

按以下顺序逐条判定，任一条不满足即标注原因：

1. **设备类型匹配**：单梁/双梁/门机/冶金/防爆等与招标标的一致。
2. **规格匹配**：起重量、跨度、工作级别不低于招标要求（低于即为不满足，不可用"接近"代替）。
3. **时间匹配**：满足公告的业绩年限要求（如"近三年 2023-09-01 以来"，以签订时间或验收时间为准，按公告口径）。
4. **金额匹配**：若公告设业绩金额门槛，按合同金额判定。
5. **使用单位匹配**：若公告限定行业（如矿山、电厂、港口），需使用单位属该行业，写清依据。

判定结论只允许三种：

- ✅ **可投标**：字段齐全、匹配度满足、佐证齐备
- ⚠️ **需补证**：匹配但缺发票/验收单/中标通知书，或使用单位与总包关系需说明
- ❌ **不可用**：类型/规格/年限/金额任一不满足，注明不满足项

## 3. 使用单位与总包信息核对要点

- 分包合同的"使用单位"应写最终用户（业主），总包单独列示；投标时若招标人要求"与业主直签业绩"，分包业绩不计入。
- 同一台设备出现多个单位名称时，以合同甲方为准，其余写入备注。
- 业绩表需与合同原件核对：**单位名称、金额、日期三者最容易抄错**，逐字对照。
- 项目名称与合同名称不一致时，保留合同名称，项目名称放入备注。

## 4. 输出

生成业绩台账表格（Excel 或 Word 表），列：序号 / 合同名称 / 使用单位 / 总包单位 / 合同金额 / 签订时间 / 设备与规格 / 佐证材料 / 匹配结论 / 备注。

台账末尾单列「不可用业绩及原因」，便于投标决策时排除。
