# 报名包结构与文档规范

## 1. 项目输出目录

```
03-项目输出/<项目编号-项目名称>/
├── 0-招标公告原文/      公告 PDF/Word 原件副本
├── 1-业绩资料/          本轮点名的业绩文件副本（未点名则留空）
├── 2-临时人员资料/      台账外人员的身份证/证件
├── 3-生成成果/          汇总 Word + 单份可上传文书
├── 4-汇总打包/          3-生成成果 的同步副本（交付用）
└── 执行日志-YYYYMMDD.txt 每步动作与修订记录
```

## 2. 汇总 Word 结构

1. **首页**：标题「XX项目 报名资料汇总」；项目编号 / 招标人 / 代理机构 / 投标人四行；下方「目　　录」
2. **目录行**：`序号、资料名称　[状态] …… 位置`，状态取值：已备齐 / 已插入 / 已插入·待替换 / 已插入·主体不符 / 待补反面 / 缺失
3. **正文**：按清单顺序，每类资料一个「标题2」
   - 文书类：模板段落直写，落款留盖章位
   - 图片类：图片直插，图下标注资料来源（台账登记路径）
   - 缺件：红字居中「【缺失：XXX，请补充文件】」+ 公告依据 + 补充路径
4. **末节**：报名资料核对台账
   - 表一「需上传资料」：序号 / 资料名称 / 公告依据 / 格式 / 资料来源 / 状态（异常行整行标红）
   - 表二「仅资格审核、报名无需上传」：序号 / 事项 / 公告依据 / 说明
   - 核对结论：条数统计、待处理问题、人工复核提醒

## 3. 排版参数

| 项 | 值 |
|---|---|
| 纸张 | A4，页边距上下 2.54cm、左右 3.18cm |
| 正文 | 宋体/仿宋 小四（12pt），1.5 倍行距，首行缩进 2 字符 |
| 标题2 | 14pt 加粗，段前 12pt |
| 表格 | 五号（10.5pt）或小五（9pt），带边框，表头灰底 |
| 告警 | 红色 FF0000，缺件加粗 |

## 4. 台账字段（报名资料清单.xlsx）

| 列 | 字段 | 说明 |
|---|---|---|
| 1 | 资料名称 | 与公告用语对齐 |
| 2 | 文件类型 | 图片/PDF/Word |
| 3 | 资料来源 | 目录名 |
| 4 | 是否就绪 | 是/否 |
| 5 | 文件存放路径 | **完整路径含扩展名**，常见错误是只写到目录或缺扩展名 |
| 6 | 备注 | 版本、有效期 |

## 5. 授权委托书（自有模板时）

- 抬头：`致：代理机构全称` 换行 `致：招标人全称`；无代理机构只留招标人一行
- 正文：`兹授权 XXX（身份证号：XXX）代表我公司在法律允许范围内前去贵公司洽谈、购买：<项目全称>招标文件的相关事宜，请予以办理接洽为谢。`
- 授权日期：任务当天 至 当天+1 个月
- 落款：投标人单位名称 + 法人盖章 + 日期（任务当天）
- 图片：法人身份证、被授权人身份证按模板标签位置粘贴；缺哪面就红字标注哪面
