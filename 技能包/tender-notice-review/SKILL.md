# 招标公告重点信息标记及报名资料审核 Skill

> **本规范当前版本 v1.8**
> 较 v1.7 新增【CA登记表专项比对增强规则】（纯叠加，不改动原有逻辑）：
> 1. 触发条件：公告出现 CA、数字证书、电子签章、平台CA 相关描述，同时识别出对应报名平台名称；公告全文未提及 CA/数字证书/电子签章时，跳过整套比对并标记「公告未要求CA/数字证书」。
> 2. 匹配方式：关键词简称模糊匹配（不要求公告平台名与台账A列CA简称文字完全一致）；所有匹配结果强制追加备注【CA为简称模糊匹配，请人工核对台账确认是否为本项目对应平台CA】，AI不做最终判定。
> 3. 时间比对：台账CA截止时间 与 公告投标截止时间/开标时间 比对，输出✅满足 / ⚠️CA已过期 / ⚠️台账未检索到 三类结论。
> 4. 三处同步输出：自检报告 + 汇总表板块3新增行字段（CA简称匹配结果、CA台账截止时间、时间比对结论、告警提醒）+ 公告副本绿色批注。
> 较 v1.6 新增**多文件批量解析规则**：
> 1. 支持一次上传多个招标公告（Word、可编辑PDF）批量执行标记解析；每个公告文件**完全独立处理，互不干扰**；
> 2. 每个公告分别输出：①该公告的【标记执行自检报告】②标记版副本（文件名自动增加项目名称+项目编号前缀，避免覆盖旧文件）③独立的《招标公告关键信息汇总表_【项目名_项目编号】.xlsx》——**禁止把多个公告数据合并写入同一个汇总表**，防止数据错乱；
> 3. 批量处理结束后输出**总摘要**：一共处理多少份公告、成功多少份、哪些文档因加密/扫描版无法做内部高亮批注；
> 4. 某个公告解析报错或文档不支持批注时，**不能中断整个批量任务**——跳过该公告并在总摘要告警，继续处理剩下的其他公告；
> 5. 不做跨公告对比，每个公告的时间、渠道、报名资料、重点平台匹配完全基于本公告自身内容；
> 6. 输出产物全部分开命名，禁止文件重名覆盖。
>
> 较 v1.5 新增两条强制提醒规则：
> 1. 识别到 ≥2 种报名渠道时，在 PDF 批注与汇总表板块2 备注栏强制追加「⚠️需要多报名方式同时进行：【渠道A + 渠道B + …】，全部操作均要完成，不可只做其中某一项」；

## 二、全局硬性规则（永久锁定，任何步骤不得违反）

1. **唯一依据原则**：所有数据匹配、校验、判断，只允许以两份本地 Excel 数据源 + 本次上传的招标公告原文为唯一依据。禁止主观猜测、语义乱匹配、编造信息、无依据判定合规/不合规。
2. **强制免责声明**：所有输出结果（文件、回复文本）必须强制标注：**AI仅辅助分析，所有内容必须人工逐条复核原件后才可使用，禁止直接对外提交。**报告类文件由脚本自动置顶该声明。
3. **数据源只读**：读取 Excel 严格只读（`read_data_sources.py` 已内置只读模式），禁止修改、篡改、删除本地数据源文件，禁止错乱读取表格行列。禁止向 `E:\卫华供应商入围资料库\` 写入任何文件。
4. **模糊即人工复核**：识别模糊、信息缺失、匹配不确定的内容，一律标注【需人工重点复核】，禁止私自判定结果。
5. **源文件保护**：源文件只读保护；输出文件仅生成副本，绝不移动、修改本地原始资料库文件。归集资料一律用复制（保留原件不动）。
6. **模块独立**：模块一【招标公告智能标记解析】与模块二【报名资料智能合规审核】独立触发、互不干扰。

补充执行纪律：
- 高亮/批注的 search 文本必须先从原文中精确提取（逐字符一致），标记脚本报告 unmatched 时必须重新提取重跑，禁止跳过或假装标记成功。
- 检索不到的信息明确标注【公告未提及】，禁止留空或编造。
- CA匹配必须以公告中出现的 CA/平台名称与数据源名称精确对应（含括号别名，如"国家电投（中电投）"）；名称相近但不确定的，归入【需人工重点复核】。

## 四、模块一：招标公告智能标记解析

**独立触发指令示例**：「标记公告」「解析招标公告」「招标公告标记」「关键信息标记」「批量解析公告」。用户上传招标公告（Word/PDF 可编辑格式，单份或多份）即触发。

### 批量处理模式（v1.7 新增，强制规则）

1. **完全独立处理**：一次上传多个招标公告时，每个公告文件独立走完"读取数据源→通读原文→提取片段→标记→汇总表→自检报告"全流程，互不干扰、互不共享中间状态。
2. **逐份输出，禁止合并**：每个公告分别输出：
   - ① 该公告的【标记执行自检报告】；
   - ② 标记版副本文件，文件名自动增加**项目名称+项目编号前缀**（如 `【某厂房增配行吊项目_0730-2611JP0152-06】标记版-招标公告.pdf`），避免覆盖旧文件；
   - ③ 独立的《招标公告关键信息汇总表_【项目名_项目编号】.xlsx》，**禁止把多个公告数据合并写入同一个汇总表**，防止数据错乱。
3. **单份失败不中断批量**：某个公告解析报错、文档加密/扫描版不支持批注时，跳过该公告并在总摘要中告警，继续处理剩下的其他公告。
4. **批量总摘要（批量结束后强制输出）**：一共处理多少份公告；成功多少份；哪些文档因加密/扫描版无法做内部高亮批注（对应告警与保底说明——识别结果仍完整输出在该公告的汇总表）。
5. **不做跨公告对比**：每个公告的时间、渠道、报名资料、重点平台匹配完全基于本公告自身内容，禁止串用其他公告的信息。
6. **文件命名全部分开**，禁止重名覆盖；同一项目名/编号缺失时用原文件名（去扩展名）替代前缀。

### 执行流程

1. **读取数据源**：运行 `scripts/read_data_sources.py --check-date 今天`，获得 CA 全量台账（含有效期状态）与重点平台全量清单。基准日期可按公告要求的时点（如开标日）另行指定。
2. **通读公告原文**：完整读取公告全文（docx 用 python-docx 提取全文文本；PDF 用 pymupdf 提取全文文本并记录页码）。逐段识别以下三类关键信息。
3. **提取精确片段**：对每处关键信息，从原文提取逐字符精确的文本片段（作为 search），并确定颜色与批注内容。
4. **生成标记任务 JSON 并执行**：
   - docx：`scripts/mark_docx.py --tasks 任务.json`（输出保留原格式的副本，run 级底纹高亮+批注）
   - pdf：`scripts/mark_pdf.py --tasks 任务.json`（高亮标注+弹窗批注副本）
   - 有 unmatched 时重新提取原文片段重跑，直到全部 matched。
5. **生成汇总表**：`scripts/make_summary_xlsx.py --rows 行数据.json --out 招标公告关键信息汇总表.xlsx --project 项目名`。

### 标记维度（固定不变）

**（一）时间类——黄色高亮 + 批注原文位置**（颜色代码 yellow）：
1. 招标文件获取开始/截止时间
2. 报名截止时间
3. 开标时间
4. 投标文件递交截止时间
批注格式：`【时间】类型：原文时间。位置：第X页/第X段。请人工确认。`

**（二）特殊报名方式——橙色高亮 + 批注**（颜色代码 orange）：
1. 双渠道/多渠道报名/获取文件（网站+邮箱、两个不同招标网站、线上+线下组合报名；同时存在 ≥2 种渠道即触发多渠道重点提醒）
2. 公告要求现场携带证书原件、核验原件、提交原件扫描、原件备案等所有原件相关要求
3. **v1.6 多渠道重点提醒（强制）**：当识别到 ≥2 种获取招标文件/报名递交渠道时，**每一条橙色多渠道任务**的批注以及汇总表板块2 备注栏强制追加：
   `⚠️需要多报名方式同时进行：【渠道A + 渠道B + …】，全部操作均要完成，不可只做其中某一项`
批注格式：`【特殊报名方式/原件要求】具体要求摘要。位置：第X页/第X段。⚠️需要多报名方式同时进行：[渠道A + 渠道B + …]。请人工确认并提前准备。`
强化匹配关键词集合（v1.6，含历史）：双渠道报名、线上+线下、网站+邮箱、两个平台报名、同时两个渠道获取文件、线上报名+现场提交、领取地点、递交地点、现场递交材料、邮箱发送材料、邮寄递交、现场领取招标文件。

**（三）CA/重点平台精准匹配——绿色高亮 + 权威对照**（颜色代码 green）：
1. 识别公告内所有报名平台、招标平台名称/网址，与重点平台清单逐条精确匹配（名称或域名命中）。命中即标注：平台全称、官方网址（来自清单）。
2. **v1.6 平台报名人员姓名手机号提醒（强制）**：当命中重点平台且公告存在平台注册、平台报名操作要求时，**每一条平台任务的批注**以及汇总表板块3 备注栏强制追加：
   `⚠️平台报名注意：务必使用本公司真实人员姓名、手机号完成平台注册及报名操作，不要使用个人私人账号`
3. **v1.8 CA登记表专项比对增强（纯叠加规则，不改动原有逻辑）**：
   - **数据源约定**：`E:\卫华供应商入围资料库\CA登记表.xlsx`，A列=CA名称（CA简称，非平台全称）、C列=CA截止时间。
   - **触发条件**：公告识别出现 CA、数字证书、电子签章、平台CA 相关描述，同时识别出对应报名平台名称。公告全文未提及 CA/数字证书/电子签章 → 跳过整套CA比对，标记「公告未要求CA/数字证书」。
   - **匹配方式**：关键词简称模糊匹配——公告平台名称/CA相关关键词 与 台账A列CA简称互为包含或近似即可命中，不要求文字完全一致；得到候选CA记录。⚠️所有匹配结果强制增加备注：`【CA为简称模糊匹配，请人工核对台账确认是否为本项目对应平台CA】`，AI不做最终判定。
   - **时间比对**：提取候选CA台账【截止时间】，与公告【投标截止时间、开标时间】两个关键时间比对：
     ① CA截止时间 ≥ 投标截止/开标时间 → `✅台账匹配到XXCA，CA截止时间XXXX-XX-XX，满足本项目投标/开标时间要求`；
     ② CA截止时间 ＜ 投标截止/开标时间 → `⚠️CA已过期！台账中XXCA截止时间XXXX-XX-XX，早于项目投标/开标时间XXXX-XX-XX，需要尽快办理更新CA数字证书`；
     ③ CA登记表检索不到对应CA简称 → `⚠️CA登记表未检索到该平台对应的CA证书，请核实并办理对应平台CA数字证书`。
     多条候选记录逐条给出结论，并汇总说明是否存在满足时间要求的有效记录。
   - **输出位置（三处同步带出）**：①标记执行自检报告增加CA匹配与时间比对结果；②汇总表板块3【CA与重点平台匹配信息】新增行字段：CA简称匹配结果、CA台账截止时间、时间比对结论、告警提醒；③公告副本绿色批注内带上本条CA告警文字。
   - 台账备注列含账号/密码等敏感信息时，输出只引用台账行号与位置，不复制凭据明文。
4. 清单中查不到的平台/CA：批注【需人工重点复核：权威清单未收录该平台/CA】，禁止猜测是否可用。

2. `《招标公告关键信息汇总表.xlsx》`，列：关键类型 | 具体内容 | 原文页码行数（位置） | 匹配数据源 | 状态标记 | 备注 | 人工复核确认
   - **板块2 报名及招标文件获取渠道信息**：v1.6 新增字段「重点提醒」列，多渠道时填入 `⚠️需要多报名方式同时进行：【渠道A + 渠道B + …】，全部操作均要完成，不可只做其中某一项`；单渠道填写【无】。
   - **板块3 CA与重点平台匹配信息**：v1.6 新增字段「重点提醒」列，命中重点平台且公告有平台报名要求时填入 `⚠️平台报名注意：务必使用本公司真实人员姓名、手机号完成平台注册及报名操作，不要使用个人私人账号`；否则【无】。v1.8 新增行字段：CA简称匹配结果、CA台账截止时间、时间比对结论、告警提醒（公告未要求CA时该组行标记「公告未要求CA/数字证书」）。
   - **独立工作表：投标人需准备资料清单**：序号、需提交资料名称、原文位置、递交阶段、特殊要求（原件/盖章/扫描件）、备注。
3. 未查询到的信息标【公告未提及】；模糊信息标【需人工复核原文】；无依据绝不编造。

## 五、模块二：报名资料智能合规审核

**独立触发指令示例**：「审核报名资料」「资料合规审核」「合规审核」。用户上传【招标公告 + 我方整套报名资料】时触发。若已有模块一解析结果，直接复用；没有则先按模块一流程解析公告。

### 执行流程

1. 复用/执行模块一解析，得到公告全部要求项清单。
2. 运行 `scripts/read_data_sources.py --check-date 开标日（或今天）` 获取 CA 有效期与平台清单。
3. 逐项清点我方报名资料（列出文件清单，含文件名、格式、扫描件/盖章情况），与公告要求客观比对。
4. 按六大固定维度审核（见下）。
5. 生成审核数据 JSON，运行 `scripts/render_audit_report.py --data 数据.json --out 报名资料合规审核报告.xlsx`。
6. 归集合规资料：在输出目录新建本次招标专属文件夹（如 `招标审核输出/<项目名>/合规资料归集/`），**仅复制**判定为✅合规的文件（用 `cp` 或 python `shutil.copy2`，保留原文件不动），按类别分文件夹归档（资质类/证书类/财务类/其他）。

### 六大固定审核维度（不变）

1. **漏项审核**：公告明确要求的资质、材料、证件，我方未提供的 → 列出缺失项 + 公告原文依据（页码/条款）。
2. **错项审核**：提供的资质类型、专业、范围与招标要求不匹配 → 逐条列出问题 + 双方原文对照。
3. **有效期审核**：CA证书（对照CA登记表）、人员资质、企业资质是否在招标有效周期内 → 过期/即将过期（90天内）明确预警。
4. **平台合规审核**：对照重点平台清单，核查资料是否符合对应平台报名、签章、上传规范。
5. **格式审核**：核对文件格式、扫描件要求、盖章要求、原件扫描要求是否达标。
6. **命名审核**：核对文件命名是否符合招标及平台规范。

### 判定规则（硬性约束，永久锁定）

- **✅合规项**：有数据源/公告原文明确依据且完全一致的项。
- **❌错误/缺失项**：有公告原文明确依据且客观不一致/缺失的项，必须附公告原文依据和修改补充建议。
- **⚠️人工必复核项**：无数据源、无公告原文依据的问题一律不判定、不瞎提示，直接归入此类；文字近似、语义模糊、无法精准匹配的内容绝不私自判定对错，全部列入并说明核对方式。
- 只客观罗列差异、漏项、错项，不夸大、不编造、不主观预判招标结果。

### 模块二固定输出（不变）

1. `《报名资料合规审核报告.xlsx》`：✅合规项 / ❌错误缺失项（附修改补充建议）/ ⚠️人工必复核项 三类分节展示，附六维度结论与归集清单，强制兜底声明置顶。
2. 合规资料归集副本文件夹（仅复制、自动分类，原文件不动）。
3. 回复中置顶提示：本AI审核仅为辅助参考，存在识别盲区与匹配误差，所有资料、资质、有效期、报名要求务必人工对照公告原件及证书原件二次复核，确认无误后方可报名提交。
