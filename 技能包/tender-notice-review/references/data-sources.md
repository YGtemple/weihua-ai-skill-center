# 权威数据源结构说明（只读）

两份数据源永久固定绑定，本文件描述其表结构，供匹配时正确读取行列，禁止错乱读取。

## 1. CA证书权威数据源

- 路径：`E:\卫华供应商入围资料库\CA登记表.xlsx`
- 工作表：`Sheet1`（Sheet2/Sheet3 为空）
- 表头（第1行）：

| 列 | 字段 | 说明 |
|---|---|---|
| A | CA名称 | 如：内蒙古电力、E招冀成、华润守正移动CA、中招互联等。部分名称含括号别名 |
| B | 起始时间 | 格式不统一：`2022.04.08`、`2024.9.29`、datetime 单元格等 |
| C | 截止时间 | 同上。用于有效期校验 |
| D | 备注 | 登录手机号、价格、小程序、无U盘类等使用说明 |

- 约 500 行数据。日期解析必须用 `scripts/read_data_sources.py` 中的 `parse_date`（兼容 `.`、`-`、`/`、`年月日` 及 datetime 单元格），解析失败的行脚本会标【需人工重点复核】。
- 有效期状态判定（客观日期比对，基准日默认今天，可按公告时点指定）：
  - `已过期`：截止日期 < 基准日
  - `即将过期（剩余N天）`：0 ≤ 剩余天数 ≤ 90
  - `有效`：剩余天数 > 90
  - `尚未生效`：基准日 < 起始日期
  - `截止时间无法解析【需人工重点复核】`

## 2. 招标重点平台权威数据源

- 路径：`E:\卫华供应商入围资料库\重点平台清单.xlsx`
- 工作表：`Sheet1`（Sheet2/Sheet3 为空）
- 表头（第1行）：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 网站注册名称 | 如：国家电投（中电投）、中国华电集团公司招标与采购网、云筑网等。括号内为别名 |
| B | 网址 | http/https 或裸域名，格式不统一 |

- 约 50 行数据。
- 匹配规则：公告中出现平台名称或网址时，需同时做**名称精确/别名匹配**与**域名匹配**（清单网址与公告网址比对注册域名，注意 `www.` 前缀与协议差异）。
- 清单未收录的平台：标注【需人工重点复核：权威清单未收录该平台】，禁止猜测。

## 3. 匹配纪律

- 匹配命中必须能指出数据源的具体行（如"CA登记表 第5行"），无法指出依据的不算命中。
- 名称相近但不完全一致（如"中招联合"vs"中招互联"）：视为不同条目，若无法确定对应关系，归入【需人工重点复核】。
