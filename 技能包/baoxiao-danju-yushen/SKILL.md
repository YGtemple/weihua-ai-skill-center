# 报销单据合规预审（baoxiao-danju-yushen）

## Overview

「口径加载 → 逐单核对 → 三分类 → 清单输出」。核心约束：判定依据必须是用户提供的制度口径，制度没写的项不判不合规，只标「制度未覆盖，请确认」。

## 硬性规则（违反即失败）

1. 口径先行：没有制度口径就只做完整性检查（缺附件、缺签字），不做合规判定。
2. 发票信息只读不猜：抬头、税号、金额、开票日期以票面为准，模糊处标「待核」。
3. 三类分明：合规 / 待补（缺件可补）/ 不合规（口径明确不符）。
4. 不修改、不重开任何单据，只给修改建议。
5. 涉及个人隐私的金额与身份信息，输出时汇总不逐条外传。
6. 最终审批仍由财务与部门负责人完成。

## 工作流

1. 加载用户给定的制度口径，拆成可核对的检查项。
2. 逐单抽取报销单字段与发票字段。
3. 按检查项判定并归类。
4. 汇总缺件明细与不合规原因。
5. 输出预审清单，标注可直接提交的单据。

## 产出与交付

预审清单（合规 / 待补 / 不合规三类）、缺件明细、可直接提交的单据列表。。交付时同时给出：数据来源清单、留空与待补项、需要人工复核的节点。

## 边界（不做什么）

不做税务处理、不做付款、不代填报销单；制度口径冲突时以用户当次指定为准。
