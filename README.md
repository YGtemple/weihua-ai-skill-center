# 卫华AI技能中心

把卫华集团各部门已经在用的 AI 技能，收进同一个地方。
**不懂技术，也能拉一个技能。** 复制一句话，发给 AI，按提示准备材料即可。

## 在线访问

部署地址：<https://ygtemple.github.io/weihua-ai-skill-center/>

## 这个页面有什么

- **按部门找技能**：营销与投标 7 个、品牌与宣传 1 个、总裁办与文秘 3 个，共 11 个已封装的技能。
- **每个技能一张详情页**：什么时候用 / 谁在用 / 你要准备什么 / 怎么开始 / 你会得到什么 / 大概省多少时间。
- **一句话指令 + 复制按钮**：不用学提示词，复制后把 `XX` 换成你的真实项目名就能用。
- **按今天手上的活反查**：不知道叫什么不要紧，从正在干的活倒推。

## 页面路由

| 页面 | 地址 |
|---|---|
| 入口 | `/` |
| 热门技能 | `/#core` |
| 按部门浏览 | `/#catalog` |
| 技能详情 | `/#detail/<技能名>` |
| 我的收藏 | `/#favorites` |
| 提交需求 | `/#submit` |

## 使用前提

1. 用 Chrome / Edge 打开，别用记事本或 WPS 直接双击。
2. 涉及投标、公文的结果都是**初稿**，对外前必须人工核对原件。
3. 内部资料不出内网；平台注册类技能只填不提交。

## 说明

本仓库只包含页面本体（单文件，图片与视频已内嵌，无需外部资源）。
11 个技能包、管理员配置与说明文档在内部交付包中，不在本仓库。

> 页面含内部业务信息，如不希望公网可见，可将本仓库改为私有并关闭 Pages。
