# 卫华AI技能中心

把各部门已经在用的 AI 技能，收进同一个地方。
**不懂技术，也能拉一个技能**：复制一句话，发给 AI，按提示准备材料即可。

在线访问：**https://ygtemple.github.io/weihua-ai-skill-center/**

## 仓库里有什么

| 目录 | 内容 |
|---|---|
| `index.html` | 技能站本体，单文件，图片与视频已内嵌，双击或在线打开即用 |
| `技能包/` | 11 个已封装的技能，每个目录含 `SKILL.md`（顶部有业务前置卡）、`scripts/`、`references/` |
| `说明文档/` | 00 先看这里、01 部门技能地图、02 管理员配置、03 使用规范与合规红线、04 效益测算 |
| `_配置/` | `set_library_path.py`，一条命令把技能里的资料库路径改成你们实际的路径 |
| `下载/` | `卫华AI技能中心-交付包.zip` 是全部内容的打包版；`下载/技能包/` 是 11 个技能的单包，可单独下给某个部门 |

## 11 个技能

**营销与投标（7）**
报名资料整理 · 招标公告解析 · 报名资料审核 · 供应商入围填报 · 资料清单归档 · 平台注册填报 · 内部系统查询

**品牌与宣传（1）**
宣传文案审核

**总裁办与文秘（3）**
董事长发言稿 · 总裁发言稿 · 会议纪要

生产与质量、采购与供应链、人力与财务暂未封装，页面上留了「提交需求」入口。

## 怎么用（三步）

1. 打开页面，按部门找技能，或直接搜「报名资料」「会议纪要」这类词。
2. 看详情页的前置卡：要准备什么 / 会得到什么 / 大概省多少时间。
3. 点「复制这句话」，粘给 AI，把材料一起发过去。`XX` 换成你的真实项目名。

## 页面路由

| 页面 | 地址 |
|---|---|
| 入口 | `/` |
| 热门技能 | `/#core` |
| 按部门浏览 | `/#catalog` |

| 我的收藏 | `/#favorites` |

## 说明

- **本仓库内的业务数据、项目名、供应商名均为虚拟演示数据**，不含真实客户资料。
- 涉及投标、公文的结果都是**初稿**，对外前必须人工核对原件。
- 平台注册类技能只填字段、**不会自动提交**，最后一步始终由人操作。
- 技能包默认读取本地资料库 `E:\卫华供应商入围资料库`，换路径请跑 `_配置/set_library_path.py`，不要手改脚本。
