# 02 · 管理员配置（一次性，约 1 小时）

> 读者：IT、投标组负责人、技能管理员。
> 目标：让普通同事拿到包就能用，不用自己配环境。

---

## 一、要配的四件事

| # | 事项 | 影响哪些技能 | 配不好的后果 |
|---|---|---|---|
| 1 | 资料库根目录（默认 `E:\卫华供应商入围资料库`） | 报名资料整理、招标公告解析、报名资料审核、供应商入围填报、资料清单归档、平台注册填报 | 技能找不到台账，直接报错或返回空 |
| 2 | Python 环境（3.10+，装 openpyxl / python-docx / pymupdf） | 除「宣传文案审核」外基本都要 | 脚本跑不起来 |
| 3 | 内部系统只读账号 | 内部系统查询 | 只能查到公开信息，7 个模块拿不全 |
| 4 | 需求收集与排期人 | 技能站的「提交需求」 | 需求提交后没人接，热度掉光 |

## 二、第 1 件：资料库路径

### 2.1 默认约定

所有投标类技能默认读取同一个根目录：`E:\卫华供应商入围资料库`。
如果你们实际放在别的盘或别的目录，跑一次配置脚本即可，**不要手改 17 个文件里的路径**。

### 2.2 用法

```powershell
# 先看会改哪些文件，不落盘
python "_配置\set_library_path.py" --root "D:\投标资料库" --dry-run

# 确认没问题，正式改
python "_配置\set_library_path.py" --root "D:\投标资料库"

# 想改回来
python "_配置\set_library_path.py" --root "E:\卫华供应商入围资料库"
```

脚本只做一件事：把所有技能包里的旧路径字符串，统一换成你给的新路径。改完会打印「改了哪些文件、共几处」。

### 2.3 资料库要有的文件（缺哪个，对应技能就用不了）

| 文件 | 位置（相对根目录） | 关键列 | 谁用 |
|---|---|---|---|
| `CA登记表.xlsx` | 根目录 | A 列 = CA 名称（简称，非平台全称）；C 列 = CA 截止时间 | 招标公告解析、报名资料审核 |
| `重点平台清单.xlsx` | 根目录 | 平台名称、签章/上传规范 | 招标公告解析、报名资料审核 |
| `供应商入围资料清单.xlsx` | 根目录 | 文件名、文件完整路径、备注、甲方常用别名（可选） | 供应商入围填报、资料清单归档 |
| `资质清单.xlsx` | 根目录 | 类别、证书完整名称、文件路径、状态、备注、甲方常用别名 | 供应商入围填报、资料清单归档、平台注册填报 |
| `报名资料清单.xlsx` | `招标报名自动整理\` 子目录 | 项目、平台、报名时间、资料状态 | 报名资料整理 |

> 表头尽量保持现有列名不变；要加列可以，但别改前几列的顺序——脚本按位置读。

## 三、第 2 件：Python 环境

```powershell
# 任选一台机器做一次（推荐放在技能专用目录）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -U openpyxl python-docx pymupdf
```

验证：

```powershell
.venv\Scripts\python.exe -c "import openpyxl, docx, fitz; print('ok')"
```

把这段路径记下来交给同事，或者在系统 PATH 里加一个 `PY` 变量。技能包里的 SKILL.md 已不再写死某台电脑的解释器路径，按你本机实际写即可。

## 四、第 3 件：内部系统只读账号

- 7 个模块都要能翻页取全量，**只读权限就够，不要给写权限**。
- 账号只用于查询，查完的结果由人整理进投标台账。
- 遇到权限不足就停，不要绕过（技能里已写死「遇阻即停」）。

## 五、第 4 件：导入与验收

### 5.1 导入

11 个技能包在 `卫华AI技能包/` 下，每个目录里有一份 `SKILL.md` 和 `scripts/`、`references/`。
按你的 AI 平台的技能导入方式整目录导入即可；如果平台支持 zip 单包导入，把单个目录压成 zip 再传。

### 5.2 上线前 8 条检查（逐条打勾）

- [ ] 资料库根目录已按实际路径改好，`set_library_path.py --dry-run` 不再命中旧路径
- [ ] 五份台账都能打开，表头没被挪位置
- [ ] Python 三个库能 import
- [ ] 内部系统只读账号能登录，7 个模块都能进
- [ ] 随便挑一个真实项目，跑一次「招标公告解析」，看输出的汇总表是否与公告一致
- [ ] 跑一次「报名资料审核」，确认 ⚠️人工必复核项有正常列出
- [ ] 「平台注册填报」确认到「填完停下、不提交」就停
- [ ] 技能站的「提交需求」能生成草稿，且收件人明确

### 5.3 已做的改造（接手时要知道）

- 品牌口径统一为「卫华」：原「大方控股集团 / 大方重机 / 百年大方」等表述已改为卫华口径；如要保留原品牌，把 `_build/retrofit.py` 里的替换表改回去重跑。
- 会议纪要目录由 `dafang-meeting-minutes` 改名为 `weihua-meeting-minutes`，模板里的公司行、会议主题也已同步。
- 人名与个人电脑路径已清空（原写死的某同事 Python 路径、某业务负责人姓名）。
- 每个 `SKILL.md` 顶部新增「业务前置卡」，写清部门、准备、产出、省时、复核与一句话指令。

## 六、常见故障对照

| 现象 | 大概原因 | 处理 |
|---|---|---|
| 脚本报「找不到文件」 | 资料库路径没配 / 盘符变了 | 重跑 `set_library_path.py` |
| 读到空数据 | 台账表头被改、列顺序被挪 | 恢复表头，或按新表头改 `references/data-sources.md` |
| 日期读成一串数字 | Excel 日期序列号 | 技能已内置转换，若仍出错，把该列改成文本再跑 |
| 导入后技能名乱码 | zip 中文名编码 | 用 7-Zip 解压后单目录导入，不要直接传原 zip |
| 结果缺部门/缺部署 | 录音或逐字稿不全 | 补素材重跑，不要靠猜补 |
