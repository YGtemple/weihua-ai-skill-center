# 03 · 使用规范与合规红线

> 这一篇是给复核人和部门负责人看的，也是给每一个使用者看的。
> AI 出的是初稿，责任在签字的那个人身上。

---

## 一、五条红线（任何情况下都不能破）

1. **数据不出内网。** 资料库文件、内部系统截图、客户信息，只在本地或内网环境处理，不上传到外部网盘、公网模型或聊天工具。
2. **只读源库。** 所有技能对资料库只读，输出一律是副本。任何人不得让 AI 直接改写、删除、移动台账原件。
3. **人工复核后才对外。** 投标资料、公文、对外宣传稿，必须由责任人逐项核对原件。AI 标了 ✅ 也只是「按规则看没发现问题」。
4. **不自动提交。** 平台注册、报名、投标递交这类动作，AI 只填不点。最后一下必须人点，且点之前再看一遍。
5. **结果留痕。** 每次输出保留文件、时间、操作人、输入材料清单，方便追溯「这版是谁让 AI 做的」。

---

## 二、各技能必须人工看的地方

| 技能 | 必须人看的点 |
|---|---|
| 报名资料整理 | 业绩使用单位与总包信息是否真的一致；红字标注的缺件是否真的缺 |
| 招标公告解析 | 报名截止时间、递交方式、CA 要求是否与原文一致；多份公告有没有被合并错 |
| 报名资料审核 | ⚠️人工必复核项逐条过；截图类资料（营业执照、信用中国等）AI 不能判内容，必须人眼看 |
| 供应商入围填报 | 调查表里「业务/资质」自评项是否与实际相符；空白项为什么空白 |
| 资料清单归档 | 【候选-人工甄别】前缀的文件是否选对；分类是否符合甲方口径 |
| 平台注册填报 | 所有字段与资质清单是否一致；提交前再核一遍主体名称 |
| 内部系统查询 | 同名公司是否选错；金额单位（万元）换算是否有误 |
| 宣传文案审核 | 「须改」项的改后句是否符合本意；称谓、职务、姓名是否与官方口径一致 |
| 董事长/总裁发言稿 | 经营数据、表彰名单、任务指标逐条核；两位讲话人的口径不能串 |
| 会议纪要 | 有没有漏部门、漏部署；决议、责任人、时间节点是否与会上说的一致 |

---

## 三、不许拿它做的事

- 不许用它伪造、补造业绩、资质、证书、合同。
- 不许用它改写台账原件或覆盖历史版本。
- 不许用它代签、代批、代提交任何对外文件。
- 不许用它处理与工作无关的个人隐私数据。
- 不许把内部资料喂给未经审批的外部 AI 工具。

---

## 四、责任怎么分

| 环节 | 责任人 | 说明 |
|---|---|---|
| 提供材料 | 业务经办人 | 材料不全，结果一定不全；缺料不要靠猜补 |
| 使用技能 | 业务经办人 | 按前置卡准备，按一句话指令执行 |
| 结果复核 | 部门复核人 / 签字人 | 对外文件的正确性由签字人负责 |
| 技能维护 | 技能管理员 | 规则变更、台账结构变更时同步更新技能 |
| 数据权限 | IT / 系统管理员 | 只读账号、访问范围、日志留存 |

---

## 五、出问题怎么处理

1. **结果明显错**：先停下，不要拿去用；保留输入材料与输出快照，报给技能管理员。
2. **怀疑数据外泄**：立即停止使用，报 IT 与部门负责人，按公司信息安全流程处理。
3. **误操作改了源库**：立刻从备份恢复，登记事故，别在原文件上继续改。
4. **同类问题重复出现**：不是个案就是技能规则有漏洞，记进需求清单，排期修技能，不要让大家各自手工绕过。

---

## 六、给使用者的一段话

这套东西的价值不在「AI 多聪明」，而在**把老师傅的做法固化成谁都能照着做的流程**。
所以两件事最重要：材料给全，结果人看。做到这两条，省下来的时间才是真的省下来。
